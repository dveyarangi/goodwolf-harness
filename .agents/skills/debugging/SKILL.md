Mechanism: debugging

What a tree shows of its own working is installed text: this mechanism's rules, each conditioned
on the `debug` its local file sets — at `on` the block shows the working, at `off` it holds the
plain reading that keeps it out. A session reads no switch to know which; read the installed block
where it lands, never a switch.

Asked what a mark, a table or a line is, answer from the rule that installs it, by its id in the
block; asked where it is authored, name the mechanism's rules file beside its doc. Asked to switch
it, hand the ask to `/harness`, whose occasion it is.
