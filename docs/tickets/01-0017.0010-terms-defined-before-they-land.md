# A term reaches a record only if the glossary defines it

- **Status:** In progress (align underway)
- **Type:** HITL
- **Related:** [01-0018](./01-0018-reachability-coherent.md) — owns whether a shared fact may be
  restated at tier 1 *because* it is needed there, which is the same question this ticket's
  tier-1-plus-injection shape asks; [01-0011.0050](./done/01-0011.0050-shape-checked.md) — group
  targets cannot resolve until every skill is named by a mechanism or allowlisted
- **Answers:** [q-0024.0001](../questions/q-0024.0001-how-is-a-term-kept-out-of-a-record-until-the-glossary-defines-it.md)
- **Outcome:** A term used as shared vocabulary is either defined in the glossary or is stopped as
  a decision before it reaches a record, every glossary rule has one authored home, and the rule
  that enforces this is where the occasion is rather than inside one skill nobody had invoked.

## The rule was loaded, and it lost

On 2026-09-10, mid-align, I used **facet** through three exchanges as though it were settled
vocabulary until the user stopped and said they were missing the context. The word is in neither
glossary. `/align` was in my context the whole time, and it carries this:

> *When the user uses a term that **conflicts with** the existing language in `docs/glossary.md`,
> call it out immediately.*
> *This cuts both ways: before **you propose a name**, check the glossary yourself.*

**Both clauses fire on conflict with something present. Neither can fire on absence.** "Facet"
conflicted with nothing, because it was not there. And nothing was experienced as *proposing a
name*: the word was lifted off [01-0010.0110](./done/01-0010.0110-project-facets-injected.md)'s title,
so it arrived already feeling like vocabulary. The rule guards **coining**; the observed failure
mode is **inheriting**.

Under the entry file's *Self-improvement* rule — a rule present that did not fire was phrased
wrong — this is a phrasing defect and not a placement one alone. The proposed rephrasing, which
fires on the specimen where the current text does not:

> **A term used as if it were shared vocabulary is either in the glossary or is not vocabulary
> yet.** Appearing in a ticket, a title or a doc is not being in the glossary. Using one that is
> not there is a decision, not a wording choice — stop and ask.

**What is deliberately not a defect.** The glossary records themselves, their format, and the
collision rule between the method's vocabulary and a project's, which have all held. What failed
is that no rule fires at the moment a word is used, and no single place owns the ones that exist.

## What to build

This is the decision-bearing phase. Its `/align` produces the mechanism; `/mechanism` governs the
declaration and `/ticket` decomposes what remains.

- **A glossary mechanism, declared to the shape.** Its instruction file is a `/glossary` skill
  that does not exist yet: aligning a term and writing it to the glossary file inline is what that
  skill defines. `GLOSSARY-FORMAT.md` leaves `/align`'s shelf and becomes this mechanism's.
- **Two records, opposite ownership.** The method's vocabulary in `.agents/glossary.md` travels
  with core; a project's own in `docs/glossary.md` is the instance's outright. One mechanism holds
  both, and the ownership rule settled at
  [01-0010.0110](./done/01-0010.0110-project-facets-injected.md), now
  [the install spec's](../spec/01-0010.0130-harness-installs-into-another-tree.md#ownership-one-axis),
  says what redeployment may do to each.
- **The rule lands at tier 1, in its shortest form**, because the occasion for *use the project's
  words* is every output rather than every `/align`. Tier 1 is 126 lines and its scarcity is why it
  works, so the `AGENTS.md` block is the shortest thing this mechanism writes. *(This was to be the
  first injection into `AGENTS.md` by any mechanism; on 2026-09-20
  [01-0010.0110](./done/01-0010.0110-project-facets-injected.md) landed the first — the shape's R7 and
  the project's local block under *Project-local* — and set the convention this ticket reuses:
  the anchor is the heading of the section the block belongs to.)*
- **The longer form reaches the point of use by injection**, because per-skill text can carry more
  than tier-1 compactness allows *(the user, 2026-09-10)* — tier 1 carries the trigger, the
  injected block carries the procedure.
- **Six homes collapse to one.** `/align`'s two sections, the format shelf, the two glossaries'
  preambles, the one-liners in `/implement`, `/tdd`, `/dream`, `/edge`, `/skill-up`, `/recall` and
  `TICKET-FORMAT`, and the relied-on row in three mechanism docs.
- **A wording inconsistency is a HITL call** *(the user, 2026-09-10)*, not a repair the agent takes
  under repair-and-report: choosing the project's word is a decision.
- **Explicit targets now.** Group targets — inject into every mechanism of a kind — are held in
  the store as [q-0005](../questions/q-0005-how-does-a-group-install-target-resolve-to-a-file-and-an-anchor-in-each-member.md),
  a justified concept, and are not built here.
- **The eventual group is `recording`, and today it selects everything.** Kept here because the
  class is this mechanism's reason rather than the group machinery's: a skewed term in a
  conversation dies with the session and a skewed term in a record is quoted for a year. All three
  declared mechanisms are record-bearing, so the class has no discriminating power until the first
  non-record-bearing declaration — `/impact`, `/discover` and `/advise` are the candidates, each
  returning material into someone else's record and owning none. *record-bearing* is already used
  by R1 and is **not a declared field**; promoting it to one is the work. It is judged once, by a
  person, at declaration, and derived every time after.
- **The first entry names an amendment that is not yet made.** `/align`'s concerns rule and
  `TICKET-FORMAT`'s decision-bearing-ticket rule do not name each other, so both were satisfiable
  and salience decided. The wording lands with
  [01-0017.0010](./01-0017.0010-terms-defined-before-they-land.md), which is already rewriting
  `/align`'s neighbouring sections.

## Acceptance criteria — provisional, firmed at the align

- [ ] The glossary mechanism is declared to the shape and `mechanisms.py --check` passes over it.
- [ ] A `/glossary` skill exists as its one instruction file, and it defines aligning a term and
      writing it to the glossary inline.
- [ ] Every glossary rule in the tree is either in that mechanism's rules file or is an installed
      block written from it; none is a hand-written restatement.
- [ ] `AGENTS.md` carries the rule as an installed block, and the block is shorter than any other
      section of the entry file.
- [ ] The rephrased rule fires on the recorded specimen: a term present in a ticket title and
      absent from the glossary is stopped.
- [ ] A wording inconsistency raises a human decision rather than an agent-taken repair.
- [ ] `GLOSSARY-FORMAT.md` sits with its mechanism and `/align` no longer shelves it.
- [ ] `/verify` has been run on this ticket against its ticket, RFC, and governing docs.
