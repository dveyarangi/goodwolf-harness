## What to build

Cursor's hooks before a tool and before a file is read are answered by the same script. A hook
that fails there lets the call through unless told otherwise, so the entry is written to refuse
on failure; whether its hooks fire in its command-line agent is not stated in its documentation
and is written at the [hosts edge](../edge/hosts.md) as observed.

## Acceptance criteria

- [ ] In Cursor a read, a change and a shell command that name a listed file are each refused,

- [ ] A hook that fails refuses the call — observed live, or recorded as not held.
- [ ] Cursor's record at the hosts edge says what was seen, its command-line agent included.
