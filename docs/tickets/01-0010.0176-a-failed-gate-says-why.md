# A failed install gate says why it failed

- **Status:** Ready
- **Type:** AFK
- **Trigger:** [issue 4](https://github.com/dveyarangi/goodwolf-harness/issues/4) — a failed
  script gate's report keeps only the last three lines of the script's output, which for a JSON
  report are its closing brackets
- **Answers:** [q-0018.0020.0009](../questions/q-0018.0020.0009-how-does-an-install-report-show-why-a-gate-failed.md)
- **Outcome:** When an install, update or check fails a script gate, its report carries the
  failing script's diagnostics, so the person reads the reason without running the check again.

## Parent

[Shared harness across projects](./01-0010-dev-harness-shared-and-local.md), its

## What to build

- A failed injector or shape gate reports the script's diagnostics, not the tail of its output.
- A passing gate stays as short as it is today.

## Acceptance criteria

- [ ] An install whose shape check fails reports each of its diagnostics in the gate's entry.
- [ ] An install whose injector check fails does the same.
- [ ] A passing gate's entry is no longer than today's.
- [ ] `/verify` passes against this ticket, its RFC and the governing docs.
