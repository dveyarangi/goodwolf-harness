## What to build

- **A launcher core tracks**, run by the clone's `pre-commit`: it lists the commit's files from the
  index Git hands it, matches them in the shell against what each check reads — its own records or
  another's, the map standing in the launcher until each mechanism's table of its records carries
  it — and starts no interpreter when none matches; otherwise it runs the woken checks side by
  side under the interpreter `--links` recorded (decisions 1 and 3).
- **The verdict** fails the commit only on a finding in a file the commit carries; a finding in any
  other file is printed as a warning; a finding a check reports with no file fails it, since it
  cannot be placed (decision 2, and the split's hidden edge).
- **The hook** is one line, written by `harness.py . --links` where Git names it
  (`git rev-parse --git-path hooks/pre-commit`), in LF, only where none stands or the one standing
  is core's; beside another hook it leaves that hook alone and the report gives the line and where
  it goes (decision 4).
- The launcher is declared a part of the harness mechanism, under *Install adds, uninstall
  removes*, with its first-line claim.

## Acceptance criteria

- [ ] A commit named by paths that carries a question, ticket or other record whose check fails is
      refused, the finding and its file named; the same commit with the record mended goes through
      — observed live in this tree by someone who did not build it.
- [ ] A commit that carries only files no check reads runs no check and starts no interpreter,
      the launcher's own run measured.
- [ ] While another session's unstaged write fails a check, a commit that does not carry that file
      goes through with the finding printed as a warning.
- [ ] A commit of records wakes only the checks that read what it carries, side by side; its time
      is recorded on this tree's machine, and a commit of a question stays within about 3 s with
      sessions running, or what it wakes is narrowed.
- [ ] `--links` writes the hook where none stands, rewrites only its own, and beside another hook
      leaves it byte-identical and reports the line and its place.
- [ ] The hook runs from Windows PowerShell and from Git Bash on this machine.
- [ ] `/verify` passes against this ticket and the governing docs.
