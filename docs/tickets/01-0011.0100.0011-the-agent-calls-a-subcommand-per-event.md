## What to build

- `questions.py at`, `open "<question>" [--under q-P | --between q-U q-L]`, `close`, `move`,
  `depend`, `undepend`, `suspect`, `clear`, `lean` and `assign`, each with `--session`; each call
  validated and written whole, with the interference recheck the writer has today.
- `open` assigns the next free id and prints it; a race for the same id takes the next one rather
  than refusing. The window's *next free id* line goes.
- `--declare`, its grammar and its printed clause forms removed.
- Q1's examples as calls, its `nothing` gone, reinstalled — the entry contract at v19 with its line
  in the findings record; Q2's and Q3's wording; the questions skill and the mechanism doc speak
  of calls.

## Acceptance criteria

- [ ] Each event is written by its subcommand with `--session`, and a malformed call is refused
  with its usage and writes nothing; tested.
- [ ] `open` assigns the next free id and prints it, and two sessions opening at once both succeed
  with different ids; tested.
- [ ] `--declare` and its grammar no longer exist, and the skill's examples quote safely in the
  shells the hosts run.
- [ ] Q1 shows calls, the entry file announces v19, Q2, Q3, the skill and the doc speak of calls,
  and `inject_rules.py --check`, `mechanisms.py --check` and `questions.py --check` are clean.
- [ ] `/verify` has been run on this ticket against its ticket, RFC, and governing docs.
