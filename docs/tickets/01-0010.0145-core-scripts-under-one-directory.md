# Core's scripts cannot collide with a project's own

- **Status:** Partial (landed and verified 2026-09-21; frost_map's grade remains)
- **Type:** AFK
- **Plan:** [Core's scripts cannot collide with a project's own RFC](../rfc/01-0010.0145-core-scripts-under-one-directory.md)
  — `.agents/scripts/gw/` with one path constant, roots one level deeper, citations by hand, the
  grade meeting the old copy's gate
- **Depends on:** [01-0010.0130](./done/01-0010.0130-harness-installs-into-another-tree.md) (the
  install whose manifest the scripts travel in, and the gate that runs them in a recipient)
- **Blocks:** [01-0010.0150](./01-0010.0150-harness-meets-a-tree-with-a-method.md) — an install
  that integrates into a foreign `.agents/` must not overwrite a script of the project's
- **Outcome:** Every script core ships sits under one directory of its own beneath
  `.agents/scripts/`, tests included, so an install into a tree that already has scripts there
  writes beside them and never over them, and every live citation of a script names where it is.

## What to build

- **One directory under `.agents/scripts/`** holds every core script and its `test/`; the
  directory over the prefix *(the user's two options, 2026-09-21; the directory chosen at the
  `/impact` because it namespaces the tests and the bytecode cache too, and costs one root
  change)*. Each script computes the tree's root one level deeper than today; the injector,
  the shape check, the ticket maintainer, the mover, the straw-dog lister and the harness script
  all find the tree from where they sit, and the harness's gate runs a recipient's scripts at
  the new path.
- **Every live citation moves with them**: the declarations' parts tables, the usage lines in the
  scripts, the commands in the skills and their installed blocks, the local verification set,
  the core README, the root README, the ADR that names them, the architecture and the mechanism
  evidence. Archived records keep the path as it was.
- **The grade is frost_map's update.** That tree holds core at a ref whose scripts sit at the old
  paths, and its local verification set names them. Its `--update` deletes what left the manifest
  and writes the new scripts; what the report says, and does not say, about the set that now
  names nothing is recorded as the first strike for
  [01-0010.0160](./01-0010.0160-harness-edge-changes-reach-an-update.md).
