## What to build

- **A mark for the whole tree**: the point the decisions were last swept to, moved only by the
  pass that closes the sweep — not a commit's subject, which is the project's convention.
- **What landed since that mark, listed by a script** — decisions added to questions, questions
  closed, rules files and the entry file changed — across every mechanism, since dueness reads a
  mechanism's own files only.
- **`/maintain`'s section for a pass with no person**: besides what is due, the sweep; below the
  dial it repairs by subagents, commits and pushes; at or above it, it asks nothing and leaves
  each decision as an open question marked as asking the person — the question that holds it
  already, or one it opens — save in another running session's work, which it tells that
  session; tried on a fresh subagent before it lands.
- **The host's scheduled task is one line** calling that section, so the schedule the front page
  offers a reader is the harness's, not a host file's.

## Acceptance criteria

- [ ] After a decision lands that contradicts a text in another mechanism, the next pass with no
      person finds that text: repairs it where it stands below the dial, or leaves it waiting.
- [ ] A pass that fails leaves the mark where it was, and the next pass sweeps from there.
- [ ] The host's task is one line, and a scheduled run reads its instruction from `/maintain`.
- [ ] A night's run and the next morning's wake are read by a judge who did not build them.
- [ ] `/verify` passes against this ticket, its RFC and the governing docs.
