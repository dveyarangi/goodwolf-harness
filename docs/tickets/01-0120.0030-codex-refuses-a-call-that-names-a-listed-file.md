## What to build

Codex reads a file only through its shell, so the refusal there stands on the hook before a
shell command and a patch, answered by the same script as in Claude Code. Its documentation calls
that hook a guardrail and no complete boundary: what it lets past is written at the
[hosts edge](../edge/hosts.md) as observed, never assumed from the other host.
