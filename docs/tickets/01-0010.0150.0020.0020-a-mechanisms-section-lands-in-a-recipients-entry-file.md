## What to build

- **The recipient's entry file stays its own**: an install adds a mechanism's section and its block,
  an update rewrites only blocks, a removal takes the section away.
- **Anchors in a foreign file**: the section is added where the file has none.
- The import line q-0037.0006.0020.0001.0001 asked about is answered by sections instead
  ([decisions 1 and 8](../questions/q-0037.0006.0024.0002-does-every-rule-of-the-entry-file-belong-to-a-mechanism-so-that-an-install-adds-the.md#decisions)).
