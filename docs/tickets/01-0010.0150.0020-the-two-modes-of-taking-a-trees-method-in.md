## What to build

- **The first mode, as the parent's RFC planned it**: `--install` over the four places refuses
  with an inventory naming every file and every skill found, writes nothing; the skill's flow
  carries a fact or a convention into the local rules file, a project skill under
  `.agents/skills/` with its claim line, and sends to `/align` a rule against core's, a skill
  colliding by name or by responsibility, and a process of the project's own.
- **The second mode**: the project's entry file is not moved; it gains one import line for the
  harness's entry file and remains the project's own — an update never rewrites it, the hand-edit
  rule standing; the host stub stops being a shipped file in this mode; `--check` reads the line
  as arrival. The align settles, before the RFC: which rules win when the project's file and the
  harness's disagree; what an update and a check read when the entry file is the project's; and
  that the person chooses the mode at the second stop, the report recommending one.
- **The one collision both modes share**: a real skills directory where a loader link goes —
  xuanxue-cabinet's `.claude/skills/collaborate` — moves under `.agents/skills/` with a claim line
  so the link can be made, by the flow, never by the script
  ([ADR-0003](../adr/0003-one-physical-home-for-skills-reached-by-link.md)).
- Nothing of the project's is deleted by the script at any step, and the skill says so.

## Acceptance criteria

- [ ] An install into a tree holding its own entry file, a stub with content, a skill directory
      where a link goes, or a file at a path the manifest writes, writes nothing and reports every
      one of them with the skill names under each directory; an install into a tree whose
      `.agents/` holds only files the manifest does not write proceeds and reports them as the
      project's own. Behavioural tests cover each finding alone and all at once.
- [ ] An install by reference into a tree with its own entry file leaves that file the project's
      with one line added, `--check` reports arrival, and an `--update` refuses to rewrite the
      file; a test proves each.
- [ ] The skill states both modes step by step, what is amended without asking and what goes to
      `/align`, who chooses, and that the script deletes nothing of the project's; its section
      carries the line under which a mechanism's own meet-block lands.
- [ ] xuanxue-cabinet takes the install in the mode its report recommended, by the skill's flow,
      graded by the user in that tree.
- [ ] live-spec takes the install the same way, as a second check: a tree whose method is a pack
      for other projects and its own first user, its report of 2026-10-25 asking for the inventory
      mode; graded by the user in that tree.
