## What to build

A reader that prints a listed file's names and structure and never a value, whatever its key is
called, because a filter that hid values by the names of their keys has already printed one. Of a
file whose form it does not know it prints nothing, so that an unknown form fails closed. The
refusal's text names the reader's command, and the script that answers the host's call lets that
command through.

## Acceptance criteria

- [ ] The reader prints a listed file's names and structure with no value — on a fixture whose
      secret sits under a harmless name, and one whose value runs over several lines.
- [ ] Of a file whose form it does not know, the reader prints no line.
- [ ] The refusal's text names the reader's command, and that command naming a listed file is
      let through in Claude Code — observed live by someone who did not build it.
- [ ] `/verify` passes against this ticket and the governing docs.
