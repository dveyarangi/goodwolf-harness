## What to build

- A row records when its session was last seen to the minute, `YYYY-MM-DDTHH:MMZ` like the
  entries' — three hours cannot be read off a date *(the user, 2026-10-10)*.
- Every wake ends each other running row silent for three hours or more, and says nothing of it:
  the rows serve autonomous agents mostly, and a person running sessions by hand reads them as
  noise *(the user, 2026-10-10)*. No row is removed; an ended row keeps its position.
- Drawing the window turns the session's own row running again, so ending a live session costs
  one message: in Claude Code and Codex the message hook draws it, in Cursor the agent does by the
  rule.
- Silence is measured from the session's last sign of life the harness sees, so a session working
  long on one question is not ended while it works; whether that sign is its message or its write
  is the RFC's, weighed against a committed file changing on every message.
- A row in the date-only form is read as before and rewritten in the new form on its next write, so
  a tree holding core migrates without a refusal.
- The week-silent finding goes: a silent row no longer waits for a person.
- The behaviour is a straw dog bound to q-0034 at its authored homes — the skill's paragraph and a
  `TODO` in the script — until a session mechanism takes the sessions file.

## Acceptance criteria

- [ ] A running row whose session was last seen three hours or more before a wake reads ended after
      it, its position kept, and the wake's text names no ended row.
- [ ] A row seen less than three hours before stays running, and the waking session's own row is
      never ended by its own wake.
- [ ] A session whose row was ended reads running again after its next window, in each of Claude
      Code, Codex and Cursor.
- [ ] A session that keeps answering messages on one question, with no store write, for more than
      three hours is not ended by another session's wake.
- [ ] This tree's sessions file, holding date-only rows, passes the store's check before and after
      the change, and a row rewritten carries the time.
- [ ] The questions skill's sessions-file paragraph says when a row ends and who ends it, wrapped
      as a straw dog bound to q-0034; no week-silent finding remains.
