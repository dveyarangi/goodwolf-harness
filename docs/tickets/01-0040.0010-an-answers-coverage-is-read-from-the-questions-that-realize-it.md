## What to build

- **The trace link in the question store.** An optional part of a question: one or more opaque
  answer references, or derived; a store call that writes it, refusing a malformed one. A
  question's effective link is its own or its nearest ancestor's, computed when read and never
  copied. The store never resolves a reference — the development method must not know the product
  (q-0035, decision 4). Optional, so every store written before it reads unchanged; it ships to
  recipients with no edge line, the occasion rule being [01-0010.0185 an-edge-change-writes-its-line](./01-0010.0185-an-edge-change-writes-its-line.md)'s, unbuilt.
- **The `/product` skill and the product document's format** beside it: pains, goals, causes,
  answers; answers as `A<n>`, never renumbered; a row whose answer is not chosen carries a straw
  dog under the purpose root; a decided row points nowhere. A pain has no closed state (decision 5).
- **The product mechanism declared** — its doc, its rules file, its script with its tests — to the
  mechanism shape, in core (decision 11).
- **Coverage rendered on request** by the mechanism's script, never committed; in a tree with no
  product document it renders nothing.
- The window does not draw the new part: every session would pay for it every message.

## Acceptance criteria

- [ ] A trace link written on a question is read back by its sub-question as its own; a malformed
      link is refused and writes nothing; a derived question reports derived.
- [ ] Every store entry written before the part reads unchanged, and the store's tests pass.
- [ ] Over a fixture with a product document, coverage shows absent, in progress and present for
      answers realized by no question, an open one, and only closed ones.
- [ ] In a tree with no product document the script renders nothing and fails nothing.
- [ ] The product mechanism passes the mechanism shape check, and its rules file installs.
- [ ] `/verify` has been run on this ticket against its RFC, the spec and the governing docs.
