## What to build

The shape waits on its question: a file per session, which every reader of the sessions file
follows, or a writer that re-reads, compares and retries; a lock is ruled out while the harness
locks nothing ([Interruption and recovery](../architecture.md#interruption-and-recovery)). Either
way the writer's docstring says only what it keeps.

## Acceptance criteria — provisional

- [ ] Twenty sessions registered at once leave twenty session lines, in a test that starts them
      concurrently rather than in sequence.
- [ ] The wake, the window, `--check` and the conclude read every session as before.
