## What to build

The subset: the skills an amended rule reaches, read from the targets its rules file names, and
the section of the entry file it changes; the keep cases of those skills join the rule's own fix,
near-miss and bias cases. The no-instruction mode runs the rule's own cases alone. The standing
text's results are reused while neither it nor the model has changed; a model change runs every
case. The cost is a formula of the cases, stated before the run and checked after it. The author
of an amendment never sees the keep cases; the run supplies them.

## Acceptance criteria

- [ ] An amendment to an installed rule runs exactly the cases of the skills its rules file targets, and one to the entry file the cases of its section.
- [ ] A second run with nothing changed reuses the standing results and runs only the new text.
- [ ] The cost stated before a run matches the runs and judges made, and a mismatch fails the run.
- [ ] `/verify` passes against this ticket, its RFC and the governing docs.
