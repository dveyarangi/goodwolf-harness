## What to build

- Every file a mechanism declares as its part — a skill, a script, a test, a hook — opens with
  `Mechanism: <slug>`: in a skill its first body line, where an unclaimed skill already says
  `Mechanism: not yet`; in code the first line of its module docstring or header comment. The slug
  resolves to the doc by the mechanism format's directory rule, so the name can never point under
  `docs/`. A file whose format holds no comment carries none; a record carries `record of`, an
  installed block its owner, a straw dog its binding; what a script writes carries nothing — the
  decisions of q-0024.0009.0004 *(the user, 2026-10-11)*.
- The mechanism format states it, its *A skill's claim* becoming *A part's claim*, and the shape
  check holds every name equal to the parts table that lists the file. No text names the three
  existing marks as one: they work and are checked already.
- This project's architecture stops restating the install contract in its *Installing* section and
  points at the harness mechanism's doc, one home; the installer names its mechanism by the line.
