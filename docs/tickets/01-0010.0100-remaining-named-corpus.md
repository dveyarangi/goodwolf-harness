## Why this exists

Ten of the twenty selected commands remain uninstalled. The user named five of them on 2026-09-06;
`/conclude`, `/recall`, `/dream`, `/review-architecture` and `/setup-devops` stay in the parent's
backlog and are not this ticket's.

Three of the five carry
[core changes owed by later installs](./01-0010-dev-harness-shared-and-local.md#core-changes-owed-by-later-installs),
decided 2026-09-05 and unlanded:

- `/commit`, and any skill gating on permission, reads the autonomy switches from the entry file's
  local block instead of carrying its own absolute rule.
- `/skill-up` documents `<temporary until="...">` alongside `<project-local>`.
- `/edge` reconciles its callers with the actual document inventory — this project has no
  `docs/edge/`, which makes `/maintain`'s Edge-record check currently unguarded prose.

## What to build

This is the decision-bearing phase. Its align decides the split and order; it then decomposes into
children through `/ticket`, one per skill or per mechanism where several belong together — the
precedent being [01-0010.0050](./01-0010.0050-install-implement.md), which installed `/implement`,
`/tdd` and `/improve-comments` as one mechanism.

- Selection adaptations named in the corpus table are applied per skill, not assumed.
- `/commit` supplies this project's real checks locally; the selection forbids copying another
  project's test or release commands.
- `/skill-up`'s blanket appendix preservation cannot survive, per the selection; the unresolved
  override policy stays explicit rather than being quietly chosen.
- `/edge` does not create or declare normative Edge records for this project by being installed.

## Decisions this ticket's align owns

- The order and grouping of the five, and whether any belong together as one mechanism.
- Whether `/edge` arriving requires `docs/edge/` to exist, or whether the capability installs
  against an empty inventory with `/maintain`'s check explicitly unguarded until a record exists.
- Whether `/celebrate` earns installation at all — the selection says to retain the capability
  "without making celebration a completion requirement", which is close to saying it changes nothing.
