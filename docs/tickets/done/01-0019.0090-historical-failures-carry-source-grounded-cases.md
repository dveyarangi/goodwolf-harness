## What to build

Recover a full case per original failure and per recorded repeat from original chat sources,
including Claude Code transcripts. Case evidence stays with the repository so a reader needs no
machine-local transcript. The first case is independently checked for source fidelity, context
sufficiency and a check that distinguishes failure from expected behaviour before bulk extraction.

## Acceptance criteria

- [x] An independent reader validates the first extracted case before the remaining occurrences are extracted — 2026-10-27, [source fidelity and both check polarities passed](../../cases/recall-no-next-step-20261026-093907/validation.md).
- [x] Every original occurrence and recorded repeat links to its source-grounded case or explicitly states what source evidence could not be recovered.
- [x] Cases preserve source-backed host, model, timestamp and chat/message attribution, with unavailable values identified rather than inferred.
- [x] Cases include the trigger, necessary context/instructions, observed failure, expected behaviour and its check without depending on local transcript paths.
- [x] `/verify` passes against this ticket, its RFC and the accepted scope.
