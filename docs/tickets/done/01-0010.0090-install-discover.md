## Why this exists

`/discover` is on disk at `.agents/skills/discover/`, is named in `AGENTS.md`'s Helpers list, and
appears in its `Installed:` line as of 2026-09-06. It has never had a ticket.

It is also **not in the accepted bootstrap selection**. That selection, marked *Accepted by the
user, 2026-09-05*, enumerates 21 source capabilities from Meteoscape and Forecast Collector.
`discover` is not among them; it arrived from a different estate, carrying an `EVIDENCE.md` and a
`<project-local>` block that referenced `experiments/`, `memory/discovery/`, `docs/discovery.draft.md`
and a `/lurk` skill, none of which exist here.

So the entry file currently asserts an install that no decision authorises. Adding a 22nd member to
an accepted selection is a contract change, and
[the entry file](../../../AGENTS.md) says not to reopen an accepted decision without new evidence —
which makes the evidence this ticket's first job, not an afterthought.

## What to build

  [`.agents/README.md`](../../../.agents/README.md), naming this ticket as its authority.
- The filing apparatus removed from the skill body, which no longer has an artifact to file:
  the stored raw return, the register of declines, and the retirement test that measured a

- `EVIDENCE.md` reconciled against this estate: it cited `memory/discovery/`, a sibling agent by
