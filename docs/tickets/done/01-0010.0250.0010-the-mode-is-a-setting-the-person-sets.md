## What to build

A knob the session mechanism declares, its default the one shared branch, set by the person
(decision 12). It is the first setting read at run time, not only by the installer; a session
reads it from the main checkout's local file, since `local.rules.md` travels with every branch and a branch could carry
another mode. `inject_rules.py --settings` shows it; the settings edge record gains its lines;
the session mechanism's doc says what each mode means.

## Acceptance criteria

- [ ] `inject_rules.py --settings` lists the mode with its values, its default and that the
      person sets it.
- [ ] A session on a branch whose `local.rules.md` names another mode reads the main checkout's
      value; `--set branches` in a linked worktree is refused, naming the main checkout.
- [ ] A tree with no value set behaves as today.
- [ ] `/verify` passes against this ticket and the governing docs.
