## What to build

Decision 6 of [q-7ebz2f](../../questions/q-7ebz2f-how-do-sessions-on-separate-branches-share-one-question-store-and-one-registry-of-sessions.md#decisions), in place, the store still in `docs/questions/` on
`main`: an id of six random base32 characters, given by whoever opens the question; a file named
by its id and the words it was opened with, kept for good; its place only in its `part of`, the tree's structure drawn from those headers
wherever the store is shown, with no address; no `done/` folder, a closed question staying where
it is. Today's ids are converted once, with a frozen table of old to new that reads history, and
every link, binding, `Answers`, owner, lean, straw dog and `TODO q-…` in the tree is rewritten
through it. A move then rewrites one `part of` line and nothing else. The conversion is a
one-time migration, run in this tree and in each of the person's others, the harness living in
no one else's yet. The ids come before the store leaves `main`, because a
move that rewrites citations across `docs/` must be gone before no code branch holds the store.
The skills' and rules' text that says the id is the place is rewritten to what then holds.

## Acceptance criteria

- [x] Moving a question changes its `part of` line alone: its id, its file name and every link to
      it stand, and the window and the tree show it under its new parent.
- [x] A question opened gets an id of six base32 characters; two opened at once get two.
- [x] After the conversion every link and binding in the tree resolves, the store's, the tickets'
      and the straw dogs' checks pass, and an old id is found in the frozen table.
- [x] The migration, run in the person's other trees that q-ubd6uz names as migrated, leaves
      their links and checks whole.
- [x] `/verify` passes against this ticket and the governing docs. 2026-11-16, judged by a
      verifier that did not build it: criteria 1–3 met, a move tried on a copy of the tree one
      line; criterion 4 rewritten on the person's word to the trees migrated; its mends landed;
      1096 tests, every check clean.
