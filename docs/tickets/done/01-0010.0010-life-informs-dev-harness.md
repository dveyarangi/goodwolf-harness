# Life informs a smaller, observable dev harness

- **Status:** Done (2026-09-05)
- **Type:** HITL
- **Outcome:** Life's rule delivery and maintenance experience informs the dev harness, and the user can choose a concrete project-to-core-to-project propagation model.

## Parent

[A shared dev harness improves without losing project conventions](../01-0010-dev-harness-shared-and-local.md).

## What to build

Investigate Life's governing documents, relevant skills, mechanism lifecycle, rule injection, maintenance calculation, runtime delivery checks and evidence. Compare the implemented behavior with its own claims. Review the user's development-loop image for missing transitions or unnecessary stages. Propose a minimal application to this project and trace an actual style of change through project A, core and project B.

## Verification

This is research and alignment. Reading or a passing unit check does not prove that a host actually delivers an instruction into a live session. No skill synchronization, Life mechanism installation or production hook invocation is part of this ticket.

## Findings — 2026-09-05

[Research and proposal](../../research/life-harness-findings.md), [probe script](../../research/probe-life.cjs), [captured results](../../research/probe-life-results.json).

All seven fixture probes completed with their assertions satisfied. They confirm useful injection/maintenance properties and reproduce partial installation, absent-install exit-zero semantics and disk-only rules checking. These are observations about Life's current implementation, not acceptance tests for a distributor we have built. Six inspected implementation hashes remained unchanged around the probes.

## Disposition

The proposed overall propagation direction was accepted: projects propose shared improvements to core and recipients pull accepted revisions; local instructions remain inline. Detailed timing, mechanics, rule delivery and the evolving process remain with the parent ticket and draft spec. This research ticket has satisfied its criteria; it does not certify a built distributor or live host delivery. No implementation has started.
