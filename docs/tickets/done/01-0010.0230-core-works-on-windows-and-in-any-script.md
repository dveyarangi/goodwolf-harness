## What to build

- The store fits a new entry's slug so its path in `done/` stays under Windows' 259 characters
  from a clone folder of up to 128 characters, not only from this tree's own folder: a clone into a
  session's scratch folder under the user's profile is about 120, and `LongPathsEnabled=0` is
  Windows' default. Names already written are left as they stand; renaming them is the person's
  call.
- Where the checkout left store entries out because their paths pass that limit, the questions
  hook answers with why and what to do — enable long paths, or clone to a shorter folder — rather
  than drawing a window from part of the store or one line naming a missing file.
- A slug carries every word of the question in any script: lower-cased Unicode letters, digits and
  the marks written on them, composed as one form so a name reads the same from every filesystem,
  cut inside a word where a script writes none between them, and within 255 bytes a name. The name check reads the
  same alphabet, and every entry already in the store stays valid.
- The harness skill says, at its install commands, that on Windows a bare `python` may be the
  Microsoft Store stub and the `py` launcher reaches a real interpreter; the hook wrapper already
  runs the interpreter the link step ran under ([01-0010.0174](./01-0010.0174-each-hook-finds-its-interpreter.md)),
  so the skill only has to get that step run by a real one.
- What the hooks enforce is not changed: another session aligns it
  ([q-0037.0006.0005.0001](../../questions/q-0037.0006.0005.0001-which-skill-must-be-read-before-a-file-is-edited-or-a-rule-proposed-and-how-does-the-host-refuse-the-act-made-without-it.md)).

      from a 128-character clone folder, is at most 259 characters; a test fails first without the
      fit. *(2026-10-25: a verifier who did not build it saw it red under the old fit, 329 > 259)*

      passes on it; a test fails first. *(2026-10-25: red as `q-0014-2026.md`; Hindi, Thai and
      Japanese probed too)*

      entries out and no index; Claude Code, Codex and Cursor each answered with the cause, exit 0)*

      bare `python` works. *(2026-10-25; the hook wrapper's notice names it too)*
- [x] Every entry in this tree's store still passes `questions.py --check`, and the full test suite
      and the verification set are green. *(2026-10-25: 302 entries, no diagnostic; 942 tests;
      eight checks)*
