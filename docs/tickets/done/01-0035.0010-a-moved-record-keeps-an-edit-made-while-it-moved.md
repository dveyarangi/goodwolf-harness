## What to build

The mover re-checks each source against the content it derived its operations from, just before
it writes the destination and removes the source; a changed source is a refusal, reported in the
mover's form, because [Interruption and recovery](../../architecture.md#interruption-and-recovery)
calls detected interference a failure, never authority to overwrite. The citation repair already
re-checks its input; the source move is the gap.
