## What to build

- **The words have one home**: a machine shelf of the questions mechanism, beside its skill, as
  the ticket mechanism keeps the queue's arrival words. Read by nobody at session time. The
  questions doc says what the three roots are and cites the shelf for their words, rather than
  restating them — one home per fact.
- **The store's script writes the entries**: one call that seeds a store holding no entry from
  the shelf, in its order — purpose, structure, landscape — open, with nothing under them and no
  links between them. The script is the only writer of an entry's parts, so the entry format stays
  its own. An install is not a turn: the call takes no session tag and writes no session row.
- **The installer holds nothing of it**: no root words, no entry format, no rule of when to seed —
  *no constants in the installer* (the user, 2026-10-09). It runs the target's own store script
  after core is written, as its gate runs the target's own checks, and reports what it said.
- **When**: a store holding no entry, at an install and at an update alike (the user, 2026-10-09),
  as the delivery status is written whenever it is absent, so a tree that took core before this
  acquires its roots. A store holding any entry is left as it stands, and the report says so.

## Acceptance criteria

  nothing under them, and the store's check passes over it.

  holding any entry leaves every file of it unchanged, and the report says the store was left.
