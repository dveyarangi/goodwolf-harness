## What to build

A branch's copy of the store decides nothing (decision 7). The host's edit guard refuses an
agent's edit to it, and a check at push and at merge refuses a branch that carries one — a
local merge fires no pre-push hook, and a fast-forward no pre-merge one (the impact's
*Hidden edges*). A recipient's branches that touched its store before its update, as frost_map's
do, are named at the update rather than refused after it.

## Acceptance criteria

- [ ] An agent's edit to the store on a branch is refused, and a branch
      carrying a change to it is refused at push and at merge.
- [ ] `/verify` passes against this ticket and the governing docs.

## Out of scope

- Edits by hand outside any agent: the merge check holds them.
