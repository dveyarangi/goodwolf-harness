## The origin cannot violate its own prohibition visibly

*Core and instance* has been a rule since 2026-09-07 and
[ADR-0002](../adr/0002-core-may-not-depend-on-the-instance-half.md) has recorded it since
2026-09-09. Both were obeyed by review and broken by construction: in this repository every
`docs/` reference resolves, because core and instance are the same tree. The
[frost_map probe](../research/separation-probe-frost-map.md) produced 35 diagnostics on day one,
this one defect behind 28 instances (14 of them among the 35 — corrected 2026-09-11 on the probe
record), and the probe's count *missed* the four in `/verify` and `/implement`
that a link resolver finds immediately.

The [2026-09-10 `/discover`](./01-0010-dev-harness-shared-and-local.md#discover--the-premise-2026-09-10)
named the general form as its most actionable claim, family C: a prohibition the origin environment
cannot violate visibly is not enforced by review, and the remedy is not a better reviewer but a
configuration where **origin equals recipient** — so that what resolves only because the
neighbouring tree happened to be present fails on every change rather than on every port. It is the
same reason dynamic scoping was abandoned.

**What is deliberately not a defect.** The inline places — `docs/tickets/`, `docs/glossary.md`,
`docs/adr/` and their siblings, some 120 mentions. *Core and instance* permits them in as many
words, and a recipient has them on arrival because installing a mechanism creates its records.
Nor is the instance-side `evidence` bullet:
[MECHANISM-FORMAT](../../.agents/skills/mechanism/MECHANISM-FORMAT.md) puts it inside the
`<project-local>` block on purpose. The defect is a core file naming a *particular* instance
document — a leak.

## What to build

- ~~**A statement of what may reach out, before any check.**~~ **Resolved 2026-09-20, the align
  *(the user)*: there is no exemption list.** Two facts do the work, and both are already in
  [*Core and instance*](../../AGENTS.md#core-and-instance): a path convention the harness imposes
  is not a reference, and content inside an instance-owned block — `<project-local>` today,
  `<installed by="local">` once [01-0010.0110](./01-0010.0110-project-facets-injected.md) retires
  the tag — is not core's. The checker reads the enclosing block mechanically and skips it; the only
  judgment it makes is the convention boundary. **A `<straw-dog>` exempts nothing** — the shear
  strips the wrapper and ships what it wrapped, so a `docs/` link inside one dangled in every
  recipient; the entry file, [ADR-0002](../adr/0002-core-may-not-depend-on-the-instance-half.md)
  and the install spec's test bullet said the opposite until today and now agree. That raises the
  count from 27 to **50**: the 23 links inside straw dogs are violations too, and 34 of the 50
  name a ticket.
- **What a path convention is** *(the user, 2026-09-20)*: a record some mechanism declares — the
  directory that holds a kind of record, or a file that is one — and never a particular record
  inside a declared directory. `docs/tickets/` is a place; `docs/tickets/01-0020-pacer.md` is a
  document. Landed in [*Core and instance*](../../AGENTS.md#core-and-instance). The set is
  nobody's to author: it is what the declared mechanisms declare, and a recipient has those paths
  by construction because installing a mechanism creates its records. **Until the mechanisms are
  declared and their declarations parse, the check carries a holding allowlist** — every place,
  with the ticket that takes its row off. The ticket mechanism's `docs/tickets/`,
  `docs/tickets/done/` and `docs/tickets/README.md` are declared already but not readably:
  `record-bearing` becomes a parsed field under
  [01-0017.0010](./01-0017.0010-terms-defined-before-they-land.md), and those rows leave then.
  `/align`'s `docs/glossary.md`, `docs/architecture.md`, `docs/concerns.md` and `docs/adr/`,
  `/plan`'s `docs/rfc/`, `/conclude`'s `docs/sessions/` and the rest wait on their mechanisms
  being declared, [01-0017](./01-0017-io-graph-coherent.md). The list is the check's own data
  under a `TODO` naming those tickets — a file of it was tried on 2026-09-20 under `.0050` and
  refused as an index committed beside its records; when the last row is gone the check reads
  declarations only.
- **The leak check, folded into `mechanisms.py --check`** *(the user, 2026-09-20)*. A **leak** is a
  citation from core to a document only the instance has (method glossary). The check's register
  is the mechanism set — it reads the declared records and asks whether core cites anything
  beyond them — so it is a second question asked of the register `mechanisms.py` already walks,
  not a new script: mechanism-shape's part, one new moment row (*holding core to citing only what
  its mechanisms declare*), the same M1 entry, no new command in the verification set. It reads
  every `.md` and every non-test `.py` under `.agents/` — a test's `docs/` literal is fixture
  data for a tree the test builds — and classes each citation or path literal as a declared or
  allowlisted **place**, as **instance-owned** content skipped by its enclosing block, or as a
  **leak**; it reports the three classes, never a total, and any leak fails the run. A text
  resolver, not a hermetic run: the hermetic run *is* an install into an empty tree, which is
  [`.0130`](./01-0010.0130-harness-installs-into-another-tree.md)'s arrival test and catches
  there what text cannot — a path a script builds at runtime.
- **The contradiction between two core documents resolved.** MECHANISM-FORMAT mandates a markdown
  link for a `not yet` referent; *Core and instance* forbids that link. One of them changes.
  [01-0011.0050](./done/01-0011.0050-shape-checked.md)'s align owns the referent's form and this one
  must not settle it ahead of that ticket — it takes the answer and enforces it.
- **The references that are not legitimate, removed.** `docs/process.md` is not a convention: it
  is 01-0020's straw dog, whole *(the user, 2026-09-20 — the wrapper covers its first paragraph,
  the claim covers the file)*, and it holds harness rules in the half a recipient replaces — the
  one recipient has a `## Verification` of its own and no `## Autonomy and repair` at all. **This
  ticket moves the rules out** *(the user, 2026-09-20; the pacer's straw dog already says each
  step's rules belong in the step's skill, so nothing of the pacer's is pre-empted)*: the
  definition of a verification set goes into `/verify`'s body and `/implement` links `/verify`;
  the repair policy's four conditions go under the `repair` switch in
  [AGENTS.md § Autonomy](../../AGENTS.md#autonomy), whose semantics they are; this project's
  four commands go into a `<project-local>` block beside the switch block, for
  [.0110](./01-0010.0110-project-facets-injected.md) to convert with the rest. `process.md` keeps
  the sequence sketch, wrapped whole, and no core file links it — `/verify` ×3, `/implement` ×1
  and `/maintain`'s block ×1 all repoint. The grading-prose links in the mechanism docs are
  `/maintain`'s R3 (*move story out of a doc into its evidence*) and are routed there rather than
  repaired here.
- **The check fails the run**, not warns. A reporting-only check is the review it replaces.

## Acceptance criteria

- [ ] `mechanisms.py --check` enumerates every citation and path literal from a file under
      `.agents/` (tests excluded) to a path outside it, and reports each as a place, as
      instance-owned content it skipped, or as a leak — three classes, never a total; a link inside
      a `<straw-dog>` is a leak like any other.
- [ ] The check cites [*Core and instance*](../../AGENTS.md#core-and-instance) for what a leak is
      rather than restating it, and reads its places from the holding allowlist, each row wrapped
      on the ticket that removes it.
- [ ] A leak fails the run.
- [ ] The check reports zero leaks on this tree: no core file links `docs/process.md`, the
      verification definition and the repair policy live in core, this project's commands sit in
      an instance-owned block, the 34 ticket-naming links carry `.0050`'s form, and the
      grading-prose links are routed to `/maintain`.
- [ ] Behavioral tests: a planted link to a particular `docs/` document fails the run; a declared
      or allowlisted place does not; a link inside an instance-owned block is skipped; a link
      inside a `<straw-dog>` fails.
- [ ] Mechanism-shape's doc carries the new moment row and its parts table the check, through
      `/mechanism`; `mechanisms.py --check` is clean over it.
- [ ] `/verify` has been run on this ticket against its ticket, RFC, and governing docs.
