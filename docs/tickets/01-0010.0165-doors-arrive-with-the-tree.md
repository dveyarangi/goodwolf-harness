# A fresh tree arrives with its painted doors

- **Status:** Planned
- **Type:** AFK
- **Related:** [01-0010.0150](./01-0010.0150-harness-meets-a-tree-with-a-method.md) — a tree that
  already holds a door is a collision, and collisions are that slice's, not this one's
- **Outcome:** An install into a fresh tree ends with every painted door present and
  `docs/tickets/README.md` readable, so the first session's `/recall` has a delivery status to
  stand on instead of nothing.

## Parent

[Shared harness across projects](./01-0010-dev-harness-shared-and-local.md), whose

## The glossary already promises this and the install does not keep it

[`.agents/glossary.md`](../../.agents/glossary.md) defines a painted door as a path under `docs/`
*which every recipient has because installing the mechanism creates it*. No install creates one.
ai-game-1 has no `docs/tickets/`, so `/ticket` there would write into a directory that does not
exist and `/recall` — which the entry file makes the first act of every session — has nothing to
read. The harness mechanism's own Moments table already carries the row, unowned.

Deliberately not a defect: the doors being **empty**. A container with nothing in it is a true
arrival state. Only `docs/tickets/README.md` has content, because it is not a container — it is
the delivery status, and its arrival state is a claim worth writing.

## What to build

- `harness.py` creates every painted-door directory after the gate, never before: creation is a
  write, and *every refusal writes nothing* must stay true.
- The door list has **one** home. [mechanisms.py](../../.agents/scripts/gw/mechanisms.py) already
  holds it by hand for the leak check; the creator reads that list rather than copying it, so the
  two cannot disagree undetectably.
- `docs/tickets/README.md` is written with its arrival state — core arrived at this ref, nothing
  in flight, the next step is setup — and only when absent.
- A path that already exists is left exactly as it is and reported, not merged and not
  overwritten. Whether that is a collision worth refusing over is `.0150`'s.
- The mechanism's doc gains the Moments row, its `not yet` retired.

## Open issues

- Whether an empty door directory survives a `git add` in a recipient that does not keep empty
  directories. A `.gitkeep` is core writing a file into the instance's tree, which may be worse
  than the directory vanishing; decide at `/plan` against what a real recipient's git does.

## Acceptance criteria

- [ ] An install into an empty git tree ends with every painted door present, and
      `mechanisms.py --check` reports no leak.
- [ ] `docs/tickets/README.md` exists after that install and states the ref, that nothing is in
      flight, and that setup is next.
- [ ] The door list appears once in the tree; a test fails if a second copy is introduced.
- [ ] A refusal before the gate leaves no door behind.
- [ ] An install into a tree that already holds one of the doors leaves it byte-identical and
      names it in the report.
- [ ] `/verify` passes against this ticket, the RFC and the governing docs.
