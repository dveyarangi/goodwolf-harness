## The page, as the align settled it

Decided *(the user, 2026-09-26)*: the page is first for whoever asks what this is, then for whoever
wants to use it; it points into core and never into `docs/`; every house term is explained in a
clause where it stands or anchored to a practice the reader knows; the title is **GoodWolf
Harness**, *the harness* in the prose. The agreed text is the
[RFC](../rfc/01-0010.0167-the-front-page-says-what-the-harness-is.md#the-page)'s. *Not yet*'s
items, each wrapped in the page and bound as below:

## What to build

- **The root README is the page above**, its links pointing into core only; `docs/` appears in it
  nowhere but the straw dogs' bindings, which a release shears. The flow stays the harness skill's
  alone — the page names the one script it runs and nothing of its steps.
- **The license has one home, the root `LICENSE`** (MIT), and an install or update copies it into
  the receiving project as `.agents/LICENSE`, since MIT's notice must travel with every copy and
  the root never ships; `--check` compares it like any core file.
- **`/maintain`'s straw-dog listing includes the root README**, or the page's own *a script lists
  every one* is false of its own examples.
- **The README bullet [01-0010.0150](./01-0010.0150-harness-meets-a-tree-with-a-method.md) carried
  is this ticket's**, moved here at minting.

## Acceptance criteria

- [ ] The root README is the page above, and every link in it resolves into core.
- [ ] Each of the eight *not yet* items is a straw dog bound as above, and `/maintain`'s listing
      reports all eight.
- [ ] An install into an empty tree holds `.agents/LICENSE` byte-identical to the root `LICENSE`,
      an update carries a changed license, and `--check` fails on an edited one.
