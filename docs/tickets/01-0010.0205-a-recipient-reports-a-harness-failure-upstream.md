## A core defect found in a recipient stays there

The entry file's *Self-improvement* rule ships to every recipient and tells its agent to write a
rule that did not fire into `docs/rule-failures.md` — the recipient's own. frost_map's first entry,
2026-09-23, is a defect in core's straw-dog rule, found there, with an amendment proposed *for
`/mechanism`*; it reached the origin only because the user carried it. Contribution back is parked
on [the install spec](../spec/01-0010.0130-harness-installs-into-another-tree.md); this is its
narrowest, most concrete part — the report, not the patch.

Which register a failure belongs to is mechanically decidable: a rule reaching a file as an
installed block names its owner — `local`, or a mechanism of core's — and core's own text is
core's.

## Meteoscape's installer crash, carried twice — 2026-10-14

Updating from 06a2afd, meteoscape's install crashed in the injection rehearsal: the injector lists
a tree by `git ls-files`, and the rehearsal's scratch directory was no repository. The user carried
it here; [a2b8967](https://github.com/dveyarangi/goodwolf-harness/commit/a2b8967) fixed it the same
night. The reinstall that followed cloned the published repository, still at 8208fba with the fix
among ten unpushed commits, crashed the same way, and its agent recorded the defect as unfixed
upstream and worked around it with `TEMP` inside a throwaway repository. The user carried that too.
A fix that lands at the origin reaches no recipient until it is published, and the recipient
reporting a failure has no way to learn it was already fixed. The report's route has a way back
as well, and this align owns it. *(the user, 2026-10-14)*

## The align this ticket owns

- **Where it goes.** The repository the harness skill's `Repository:` line names, and its board —
  a host-specific surface; a fork reports to itself by the same line.
- **With whose consent.** Filing is outward-facing, and may be public: the person approves each
  report, and whether a switch governs it is this align's.
- **What it may carry.** A recipient may be private. The report carries the rule, why it did not
  fire and the proposed amendment — never the project's own content — and the person sees it before
  it leaves.
- **What stays in the recipient.** Whether its register keeps a line pointing at the filed report,
  so its own history is whole.
- **A repeat.** The register's own rule strikes a repeat rather than opening a second; on a shared
  board that means finding the existing report first.
- **The way back.** How the recipient learns that a reported failure is fixed, and in which
  published release, so it neither works around a fixed defect nor reports it again.
- **The rule that says all this.** *Self-improvement* is core, and already a straw dog on
  [01-0019](./01-0019-harness-amends-itself-by-explicit-meta-rules.md); both tickets will change it.
