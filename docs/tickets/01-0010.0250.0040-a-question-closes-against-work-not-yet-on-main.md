## What to build

Decision 13 of [q-7ebz2f](../questions/q-7ebz2f.md#decisions): the server records the branch a close came from;
its check, run before each commit and on request, finds the linked doc on that branch
mechanically, names the branch while it stands, says nothing once it is merged, and gives a
diagnostic once the branch is gone with the doc never on `main`. A ticket minted on a branch and
assigned as a question's owner passes the ticket check.

## Acceptance criteria

- [ ] From a worktree's branch, a question closes decided against a doc only that branch holds,
      and a ticket minted there is assigned as its owner.
- [ ] The store's check names the branch for that link, and nothing once the branch is merged.
- [ ] With the branch deleted unmerged, the check gives the abandoned branch's diagnostic.
- [ ] `/verify` passes against this ticket and the governing docs.
