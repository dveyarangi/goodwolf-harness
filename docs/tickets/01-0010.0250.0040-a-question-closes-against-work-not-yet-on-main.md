## What to build

Today the writer checks a closing answer and an owner against the files of the checkout it
runs in, which in the second mode is main's, where the branch's doc is not yet (the impact's
*Hidden edges*). The writer and the store's check take two roots — where entries live, where
links resolve — and main's check says of a link into unmerged work what [q-0037.0017.0005.0001.0002](../questions/q-0037.0017.0005.0001.0002-what-does-main-check-say-of-an-answer-link-into-work-not-yet-on-main.md)
decides. A branch's pre-push checks and the ticket check read the store through the
coordinator, not the branch's stale copy.

## Acceptance criteria

- [ ] From a branch, a question closes decided against a doc only that branch holds, and a
      ticket minted there is assigned as its owner.
- [ ] Main's store check and the branch's push say of that link what the align decided, and
      nothing once the branch is merged.
- [ ] A ticket on a branch whose `Answers` question was opened through the coordinator passes
      the ticket check.
- [ ] `/verify` passes against this ticket and the governing docs.
