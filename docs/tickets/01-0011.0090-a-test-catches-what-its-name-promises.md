## What to build

**Weak tests** — each is strengthened until deleting the line it guards fails it:
- `test_inject_rules`: a mechanism installed after the local block asserts order only; an
  off-by-one at the insertion point passes. The straw-dog-wrapped section's fixture appends a stray
  closing tag. The mid-write failure's `pending == []` holds whatever happens.
- `test_tickets`: a closed pair's latin-1 half proves nothing, since the fixture writes UTF-8.
- `test_straw_dogs`: the removal "after the final colon" never gives an operand with two colons; a
  path outside the repository is refused by the missing file before the inside-repository guard.
- move_doc: an external reference would be skipped even without the elsewhere check; a read-only
  file refuses a plain write before truncating, so the staged write goes untested.
- `test_harness`: the injector's resume asserts `inject_rules`' wording, not `harness.py`'s.

**Untested branches** — one test each:
- `harness.py`: a malformed or unopened straw-dog tag; an unclosed local block; a non-UTF-8 file at
  the ref; a `.py` leak and the `gw/test/` exemption; a copy that fails partway; a link repointed.
- `inject_rules.py`: an unknown flag; `--install` with no slug; a `# ` or `### ` heading inside a
  rule; `</rule>` before `<rule>`; two authority bullets; an ambiguous anchor at check; the spacing
  refusal on retract.
- `mechanisms.py`: a Relies-on part that does not resolve; `elsewhere` or `embedded` naming no path;
  a directory with no doc in the index; a Relies-on table without its owner column.
- `tickets.py`: an external link in a header field; a bare `Done`.
- `straw_dogs.py`: `.git` excluded from the scope walk.

**The suite off Windows** *(outside review, 2026-09-27)*. It had only ever run on Windows, and it
failed on Linux in two places: a symlink cleaned up with `rmdir`, and a read-only file that root
may write. Both were fixed the same day, unrun on Linux. A CI run on every push, Windows and
Linux, holds it there.

## Acceptance criteria

- [ ] Each weak test listed fails when the line it guards is deleted.
- [ ] Each branch listed has a test that fails when the branch is removed.
- [ ] The suite passes on Linux, as a plain user and as root, and a CI run on every push holds it
      on Windows and Linux.
- [ ] `/verify` passes against this ticket and the governing docs.
