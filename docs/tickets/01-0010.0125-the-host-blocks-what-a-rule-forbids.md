## Every rule today is trusted, not enforced

A rule reaches the agent as text, and the agent is trusted to keep it: `commit=ask` asks it to
ask, and nothing stops a commit it did not ask for. A host can: Claude Code runs a hook before a
tool call, and the hook may refuse it. The rule failures registered so far were rules the agent
never had in front of it at the moment — a delivery gap, [.0120](./01-0010.0120-host-delivery-surfaces.md)'s
— not rules it saw and broke; so the evidence for enforcement is thin, and the need is the user's
direction, not a demonstrated failure.

## The align this ticket owns

- **Which hosts.** Each hooks differently, and some may not at all; what Codex and Cursor can
  refuse is unobserved, which is `.0120`'s to find out.
- **Which rules.** Only a rule whose breach is a visible action can be refused — the switches
  (`commit`, `push`) are the obvious cases; a rule about what the agent writes or decides is not.
- **Where the configuration lives.** A hook is configured in a host file a project often already
  owns, the collision class [01-0010.0150](./01-0010.0150-harness-meets-a-tree-with-a-method.md)
  handles.
- **What it costs.** A hook runs on every matched call; the Life estate recorded launches delaying
  or losing delivery under load ([findings](../research/life-harness-findings.md)).
