# The kinds have names

- **Status:** Ready (planned 2026-10-08)
- **Type:** AFK
- **Plan:** [The kinds have names RFC](../rfc/01-0011.0110.0010-the-kinds-have-names.md) — roles
  stay and say their kind; one entry per classification; the ten names fixed
- **Answers:** [q-0024.0009.0001](../questions/q-0024.0009.0001-how-are-the-kinds-of-record-and-of-statement-named-so-that-a-reply-and-a-format-can-cite-them.md)
- **Outcome:** The method's glossary tells the four kinds of record and the five kinds of

## What to build

- The method's glossary gains the four kinds of record — *what it intends to become*, *what must
  always hold*, *what exists*, *what happened* — with the two axes that define them and expiry as
  the test between the first two; and the five kinds of statement — *instruction*, *principle*,
  *invariant*, *definition*, *classification* — each with the test that tells it from the others.
  *Principle* is rewritten: what to prefer when it is unclear what to do.
- The roles *documentation*, *record*, *evidence*, *provenance* are reconciled with the kinds:
  each either goes, because the kind says it, or stays as a declared second axis and says so.
- Every principle carries a name at its authored home: in the entry file's general section the
  bullet opens with it in bold; in a mechanism's doc and the glossary the term is the name. The
  same for every classification an agent sorts by hand — the kinds of record, of turn, of
  statement, of moment; the tiers. Enums a script reads are left as they are.
- The entry contract moves, and the findings record says what the version changed.
- No code.

## Acceptance criteria

- [ ] The glossary defines the four kinds of record and the five kinds of statement, and a
      sentence from the entry file can be placed in one kind of statement by the glossary's test
      alone.
- [ ] Every general bullet of the entry file opens with its name in bold, and every principle a
      mechanism doc states opens with its name.
- [ ] No object in the tree carries two names for the same property: a role either is gone or
      is declared a second axis.
- [ ] The entry contract's version moved, and the findings record names what changed.
- [ ] `/verify` has been run on this ticket against the spec and the governing docs.
