## What the slice turned out to be

Minted as *the painted doors arrive with the tree*. The `/plan` of 2026-09-23 found both halves
wrong and the user chose the narrowing.

**Directory doors were nearly a no-op.** `move_doc.py` already creates a record's parent on the
way in, so the first ticket written creates `docs/tickets/` itself; and git tracks no empty
directory, so a door created at install disappears when the recipient's tree is first cloned. The
glossary's promise would have been true until a clone and false after.

**The delivery status is the ticket mechanism's record**, and its arrival state is an entry in it.
`/mechanism` — *writing an entry into a record is not mechanism work; it belongs to the skill that
owns the entry*. So the text is not harness's to compose. It is authored where the record's shape
is already owned and travels in the shipment like everything else core ships.

Deliberately not a defect: that only one record arrives with content. Nothing else has an arrival
state worth writing, and a second one is what would force a general facility. Until then this is
one named seam, not a mechanism.

## What to build

- `QUEUE-ARRIVAL.md`, a shelf of the ticket mechanism's own, declares the delivery status's
  **arrival state**: what the queue says in a tree where core has arrived and nothing is in
  flight. It is a shelf and not a section of the format shelf because it is read once, by the
  install, while the format shelf is read at every ticket a session writes *(the user,
  2026-09-23)*.
- At install, `harness.py` writes `docs/tickets/README.md` from that declaration when the path is
  absent, reading it out of the shipment it already holds rather than off any disk — so what a
  recipient receives is what the ref holds, by the same rule as every other shipped byte.
- A path that already exists is left exactly as it is and reported. Whether that is a collision
  worth refusing over is `.0150`'s.
- The write happens in the writing phase, after every refusal and before the gate, so *every
  refusal writes nothing* holds and the gate judges a finished tree.
- `docs/edge/`, `docs/dreams/` and the rest of the directory doors are not created. The glossary
  says a painted door is a path a mechanism reserves; only some arrive with content.
- The mechanism's doc gains the Moments row, its `not yet` retired.
