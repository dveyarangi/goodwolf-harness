## What to build

- The form a project's code takes to name the record that governs it, and the check that holds
  the name resolving, decided at this slice's align. Core states the form and ships the check; the
  project writes its own names, and core names no project's document.
- Tried first on frost_map, whose architecture is live and whose `src` holds 34 files, almost none
  naming the record that governs it *(2026-10-11)*; eight trees on this machine hold the harness
  with code of their own.
