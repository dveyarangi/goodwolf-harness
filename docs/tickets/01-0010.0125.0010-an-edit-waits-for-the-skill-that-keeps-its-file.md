## What to build

The guard end to end for two declarations, as
[q-0037.0006.0005.0001](../questions/q-0037.0006.0005.0001-which-skill-must-be-read-before-a-file-is-edited-or-a-rule-proposed-and-how-does-the.md)'s
accepted `Where it stands` says it:

- The mechanism format gains the table — the records a mechanism writes and the parts it guards,
  each with the skill an edit needs — and the shape check reads it, since a declaration no script
  reads is a label.
- The product mechanism declares the root README under `/product`, the record whose rewrite
  without `/product` struck register entry 50 the third time. Mechanism-shape takes `/skill-up` as
  its second skill and declares the instruction files — skills, rules files, the entry file — under
  it.
- Claude Code's row in `HOSTS` declares the events that load a skill — the agent's call of
  `Skill`, the person's typed command — and its lifetime rule: the session's, until a compaction
  re-attaches within its budget. The hook keeps each load for the session and, before an edit,
  refuses one to a declared file whose skill is not loaded, naming the skill. It never reads the
  transcript, whose format the host does not promise.

## Acceptance criteria

- [ ] The mechanism format declares the table, the shape check reads it, and a row whose file or
      skill does not resolve is a finding.
- [ ] `/skill-up` names mechanism-shape as its mechanism, and the shape check holds it so.
- [ ] In Claude Code an edit to the root README with `/product` not loaded is refused, the agent
      told to load `/product`; once it is loaded the same edit goes through — observed live by
      someone who did not build it.
- [ ] The same holds for an edit to a skill's instruction file and `/skill-up` — observed live by
      someone who did not build it.
- [ ] After a compaction, a skill the host did not carry forward no longer counts as loaded —
      observed live by someone who did not build it.
- [ ] An edit to a file no table declares is never refused.
- [ ] `/verify` passes against this ticket and the governing docs.
