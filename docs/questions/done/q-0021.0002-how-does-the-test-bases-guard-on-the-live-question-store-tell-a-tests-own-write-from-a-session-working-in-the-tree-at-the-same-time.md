Opened 2026-10-12 at 01-0011.0110.0050's `/verify`. The test base fails a case after which this
tree's own question store differs from before it, on the premise that the store is written *only
by a session working in it — never by a test*. With several sessions working the tree at once,
their writes land while a case runs, and the case fails for a write it never made: across five
full runs on 2026-10-11 and 2026-10-12 one harness test failed each time, a different one each
time, every one green alone; the one traceback read *ARefusal changed this tree's own question
store* and *TheRoots changed this tree's own question store*, in a run of the harness file alone,
green on the two runs after it.

## Decisions

1. **A script given no root does not run** *(the user, 2026-10-12)*: the root a script works in is a
   required argument of its `main()`, passed explicitly by its command line from the tree it sits
   in, so a test that forgets its tree fails at the call; the test base's guard comparing the live
   store and marks before and after each case goes, its one hazard removed at the source.
   → [the test base's test](../../../.agents/scripts/gw/test/test_repository.py), *A script given no
   root*, holding every script's `main()` to a root with no default.
