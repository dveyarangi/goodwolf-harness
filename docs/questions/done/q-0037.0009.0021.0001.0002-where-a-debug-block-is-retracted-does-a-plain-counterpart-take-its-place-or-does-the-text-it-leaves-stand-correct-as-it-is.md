Most of what debug shows is an addition: retract it and the plain text reads whole — the announce
line, the lamps, the 🪢 and 🪶 tables, `/maintain`'s *what was wrong in it*. Where a sentence reads
differently either way — *A reply speaks the method*'s "the machinery is shown as well" against a
plain reply that names no script — retracting leaves the plain reading, which is already the
authored text. A swap would be needed only where the plain counterpart is text the authored file
must not carry while debugging is installed. Whether any such case exists decides whether the
injector needs a swap mode, a feature it lacks.
