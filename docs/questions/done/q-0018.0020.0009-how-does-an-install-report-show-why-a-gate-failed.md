From [issue 4](https://github.com/dveyarangi/goodwolf-harness/issues/4), 2026-10-08: a failed
script gate's `said` keeps only the output's last three lines, which for a JSON report are its
closing brackets, so the reason — the `diagnostics` — never reaches the report, and the person has
to run the check again by hand to find it.
