Debugging is no dial now (q-0037.0009.0021, decision 2), so that refusal no longer reaches it by its
letter. If installing or retracting debugging is the person's act, the injector or the harness must
refuse it from the agent the way the host refuses a dial edit; if it is the agent's, the person
asks for it in words and the agent runs it. The call is either the injector's `--install` /
`--retract` for the mechanism's slug, or a harness verb that wraps them.
