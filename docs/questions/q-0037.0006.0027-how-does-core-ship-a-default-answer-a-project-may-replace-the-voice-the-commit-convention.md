## The case, 2026-10-25

Raised in the ring on 01-0016.0030, the voice. The agent noted that rewriting core takes `/harness`'s
*in their language* away, so a recipient naming no voice would be asked for the person's language
nowhere. The person: *we need defaults — a way to install them, and a description of how they
behave in a conflict. The new commit rule is a default; the current voice rule is a default; whether
Lem stays the default I will say once I have talked with the new voice.*

What the tree holds today: a project's own answer lives in its local file (R7); a local rule may
name the core rule it replaces with `overrides <slug>/<id>`, installed after it with the citation
rendered — both texts then stand side by side in the target, the project's last. No core rule is
marked as a default, and nothing says whether an overridden rule stays or leaves.
