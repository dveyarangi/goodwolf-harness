## Decisions

1. **Only ways that carry over to a network.** The method uses only ways for sessions to reach
   each other that pass easily into a networked form, where sessions run on different machines;
   whatever works only because they share one working tree is temporary *(the user, 2026-10-25)*.
   → [session.md](../../.agents/mechanisms/session/session.md), *Sessions see each other*.
2. **The shape: one shared place, read every step.** Sessions reach each other through one shared
   place every session checks at every step, quickly, by a mechanical script; through it each gets
   its own messages and the positions of the others *(the user, 2026-10-25)*. Where it lives and
   what carries it is this question's.
3. **Today's stand-ins, each unreliable.** The rows' folder in the working tree, the commits in git,
   and a host's own messages from one session to another stand in for that place until it exists;
   none is relied on *(the user, 2026-10-25)*. So is writing into another session's question body
   to reach it.
