## Decisions

1. **A trace link names its answer by id and name** *(the user, 2026-10-13)*: `A7 "<the answer's
   name>"`, the name its row's bold lead word for word, as a ticket is named by id and slug — a bare
   id says nothing to a reader without the whole document. The id is what coverage matches; a name
   that no longer matches its row is drift, reported by the product check.
2. **Only open and decided questions realize** *(settled at the plan, 2026-10-13, reversible since
   coverage is never stored)*: deferred counts as open; a question closed pruned, moot, merged or
   superseded built nothing and realizes nothing.
