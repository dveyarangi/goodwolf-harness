**Read so far, 2026-10-11.** A token is almost all context re-read: in this tree 98.1% cache reads,
1.6% new material, 0.3% generated, thinking included; so tokens count steps times context length,
and a step's cost does not tell thought from mechanics. Typed turns per thousand lines of product
code changed came out alike in meteoscape before the harness (July–August, 104) and frost_map under
it (105), Claude Code alone; with each project's Codex sessions added, 108 and 172, Cursor's not.
Two projects at different stages compare nothing causal. The numbers and the scripts that read
them: [the first measures](../research/measures-2026-10-11/REPORT.md).

**The method's own text, against seven peers, 2026-10-11**, static, from their sources:
[context-tax-peers-2026-10-11](../research/context-tax-peers-2026-10-11.md). Before the first
message this harness reads ≈4,000 tokens against 370–2,100; per ring, ticket to commit, ≈16,900
against 16,000–20,500 for most, 6,000 and 85,000 at the ends. Only this harness injects before
each message: ≈90 tokens while the position holds, ≈4,430 here when it moves. The text is not the
tax: how many steps each method makes for the same work is not read there.
