# q-0018.0023 How does the harness reach more hosts than Claude Code, Codex and Cursor?

- **part of** q-0018
- **state** open

Opened 2026-10-08 at the front-page align (q-0031). About half the peers install into fifteen or
more hosts: BMAD about 45, Spec Kit and OpenSpec 40+, Superpowers 16, GSD and beads about 15.
The harness installs into three. The user: *more hosts are needed.*
[peer-capabilities-2026-10-08](../research/peer-capabilities-2026-10-08.md) has the lists.

The count hides depth. Most of those integrations write commands or skills into each tool's
folder, which the Agent Skills standard makes cheap. The harness's skills could reach a new host
the same way, through one more loader link or a copy. The hard part is the hooks: the window
before every message and the wake at session start. Claude Code and Codex take both; Cursor takes
only the start, so its agent draws the window by the rule. A host is reached in full only when
its hooks can carry both, and otherwise the rule is the floor.

Unsettled:

- **Which hosts first**, and by what — users asking, hook support, or the peers' lists.
- **What counts as supported** — skills found, the entry file read, hooks wired.
- **How support is checked** — whether a host reads the loader link is unobservable from inside
  a tree; see q-0018.0004.0001 "How is it observed that a host reads the loader link?".
