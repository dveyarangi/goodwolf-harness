The mirror of q-0024.0003, a target dropped rather than added. Met 2026-10-09 in a fresh recipient:
its local file's L3 was removed with its only target, `.agents/skills/verify/SKILL.md`, and
`inject_rules.py local --install` left the L3 block there — install and retract walk only the
targets the rules file names now, and `--check` reports the block as one nothing owns, with no mode
that removes it. The recipient's agent put the earlier local file back byte for byte, retracted,
then installed the new one; the tree had no commit to restore it from, so the remedy held only
because the agent still had the old text.
