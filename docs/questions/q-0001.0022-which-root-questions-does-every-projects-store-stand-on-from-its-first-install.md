The user, 2026-10-09, on what each root asks of a person: the purpose is agency itself — an
operator picks, from the space of ideas, the project's goal; it is the main judgement and
alignment. The structure needs agency mostly where the model is ineffective, suboptimal or

where the model misses. Strategy starts from the situation, so the landscape sets the purpose at
the start — the harness was chosen because the world and the user both want one; then the project
grows flesh, tactics begin, and the purpose can no longer turn into a dating site. That shift of
weight across the life of a project is q-0001.0022.0001.
