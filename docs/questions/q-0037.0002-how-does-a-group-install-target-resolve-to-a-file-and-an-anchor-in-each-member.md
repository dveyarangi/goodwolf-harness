## Where it stands

**The problem.** The installer writes a mechanism's rules only into targets its rules file names one
by one, a file and an anchor line, and refuses a target whose anchor is missing. A mechanism that
must reach files it cannot know in advance — the voice, into every skill that speaks, skills of a
tree it never saw included — cannot be installed. The lean of 2026-09-10 named the gap: a group
name is not an address, so membership is declared from both ends.

**The shape agreed.** A row of a rules file's anchor table may name a group: its target a path
pattern, its anchor the heading a member holds. A file the pattern matches is a member exactly when
it holds the anchor; the rest are passed over, not refused. Every rule that holds an explicit target
holds each member — installed in each, drift refused unless overwritten, a block in a file no
longer a member owned by nothing and taken out by the next install, an anchor held twice refused,
retraction from every member. A group with no member is neither a refusal nor a finding.

**What changes.** The installer and its check learn the pattern row; the format's anchor table, the
mechanism skill's *Refuse rather than guess* and *installed in every target it names*, and the
architecture's *Installed blocks* are rewritten through it — the five places wrapped as straw dogs
bound here.

**First consumer.** The voice, q-0037.0009.0021.0002: one block under `## What the person hears` in
every skill that holds it.

## Decisions

1. A rules file names a group by a row of its anchor table whose target is a path pattern —
   `.agents/skills/*/SKILL.md` — and whose anchor is the heading a member holds; a file the pattern
   matches is a member exactly when it holds the anchor, and the rest are passed over, not refused.
   Membership is declared from both ends, the pattern at the mechanism's, the heading at the
   member's *(the user, 2026-10-25; the voice, q-0037.0009.0021.0002, its first consumer)*. Not: a
   named group each member also declares by a mark of its own — a member would declare itself
   twice. Edge: a pattern sees only where it looks; a recipient keeping its own skills elsewhere
   needs a wider pattern or a second row.
2. A group's members are held as an explicit target is: a member holding the anchor without the
   block, a drifted block, a block in a file no longer a member — which the check calls owned by
   nothing and the next install takes out by retraction's cut — an anchor held twice, refused, and
   retraction from every member. The one rule new to groups: a group with no member is neither a
   refusal nor a finding, a tree may hold none *(the user, 2026-10-25)*.

where it looks: a recipient keeping its own skills elsewhere needs its own row.
