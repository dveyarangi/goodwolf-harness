## Decisions

1. **The mark back is the `Mechanism:` line** *(the user, 2026-10-11)*: every file a mechanism
   declares as its part — a skill, a script, a test, a hook — opens with `Mechanism: <slug>`, in a
   skill as its first body line where an unclaimed one already says `Mechanism: not yet`, in code
   as the first line of its module docstring or header comment; the slug resolves to the
   mechanism's doc by the format's directory rule, so core never names a path under `docs/`. A
   file whose format holds no comment carries none; a record carries `record of`, an installed
   block its owner, a straw dog its binding, and what a script writes carries nothing.
   `mechanisms.py` holds the line equal to the parts table. Stated in the mechanism format, its
   *A skill's claim* becoming *A part's claim*.
2. **No text names the three existing marks as one** *(the user, 2026-10-11)*: the installed
   block's owner and the straw dog's binding already work and are checked, and a paragraph naming
   them together gives a reader nothing to act on; 01-0011.0110.0050's first criterion is
   rewritten to the line and its check.
3. **A project's own code is a slice of its own** *(the user, 2026-10-11)*: first agreed as
   deferred on the agent's premise that no second shape exists, which looked at this tree alone;
   the user pointed at the recipients — eight on this machine hold their own code under their own
   architecture, almost none of it naming what governs it. Its record names a section of an
   architecture or an ADR, not a mechanism, so its form and check differ; tried first on
   frost_map, under q-0024.0009.0004.0002, which supersedes the deferral → [the queue](../tickets/README.md).
