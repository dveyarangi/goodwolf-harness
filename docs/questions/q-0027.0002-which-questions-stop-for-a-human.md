**A mark on questions, the user, 2026-10-09**, from q-0018.0011.0004. A question the harness
generates from what it finds in a project's code waits on the person to confirm it: *in effect a
HITL ticket. We need that mark, because some questions the agent may close itself under an
authorization mechanism — or under whatever is implied today, that the person steps in on what
bears load or somewhere else — which we don't have either.* So a question carries HITL or AFK as a
ticket does. Which value it gets is this question's threshold, and who may close it is a right
over the store (q-0016).
