## Where it stands

What an agent says to the person is set apart from the work it does unseen. A skill's speech stands
in its section `## What the person hears`, written in the person's words — what they learn, what
they decide; the rest of a skill is work, and work is not told. The entry file's *A reply speaks the
method* says so once: *the method's step as the person would name it* where it now says *the step*,
and *what the work read, ran or wrote, and what it will read next, is not told; what more the person
hears at an occasion, a skill's speech section says, in their words.*

A bench grades it: a case is the person's message, what the host gave the session, and the tree's
rules at a commit; a fresh agent writes the reply, debug off; a second, given only the message and
the reply, answers whether it tells the assistant's own workings, quoting the sentences. Five runs a
case, counted. A change to a speech section or to the entry file's rule is run red before and green
after. One good reply sits in the set, so a reader that flags everything is seen.
