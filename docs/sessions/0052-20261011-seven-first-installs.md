- **record of** what happened

The user installed the harness into an emptied project seven times in one day and brought each

## Decisions

- **The line runs inside a skill, not between skills; it is drawn in what the reply says**
  (q-0024.0012). Three layers, the user's words: the *method* — what the self-improvement promise
  promises to improve: the loop, the stops, the reply's form, the questions, the tickets' acts;
  the *practice* — what a project swaps; the *machinery* — what carries both, which a person
  knows of only in debug mode. A skill's instructions keep every call they need — the user:
  *the mechanism doc is no place for instructions; they have to know* — so no text moves; the
  entry file's own machinery is q-0026.0006's. Landed as v77, *A reply speaks the method*, a
  straw dog bound to q-0024.0012; `debug` thereby gains a second meaning, the machinery shown.
  Refuted on the way: a debug mode against a user mode of the reply — *which question we stand on
  and the steps are the product*; a sidecar derived from the product document — *why not just
  copy the README*; moving descriptive machinery into mechanism docs — rule failure 40.
- **The gloss *the development method and its machinery* was a misreading** of 2026-09-07,
  struck from the method glossary's **Mechanism** and `/mechanism`; the membership test stands.
  What was meant: the method, once separated from the machinery, is a candidate mechanism of its
  own. Recorded in the shape's evidence.
- **The install ships the front page itself** beside the harness skill, as it ships the license
  — the origin's own document, not core text: no second text derived, no commit links, no
  picture (linked in the repository at `main`); the leak rule does not read it and the shape check
  reports its citations as skipped. An install from `main` had refused since 41fa4da on the
  README's link to `docs/research/`.
- **A clean clone of the origin standing where the project was meant is turned into an install
  in place** — `--install --replace-clone` — because what a host makes of *install <url> here* in
  an empty folder is the origin cloned into it before any text is read, and the agent may not
  delete what it cloned. The front page says *beside your project — never into it* and names the
  recovery. The seventh install ran the whole path as designed.
- **The first install's last step**: the entry file, arrived mid-session, is read; the harness is
  introduced from the shipped front page before anything is asked; each answer asked in the
  person's terms, never as a switch's name and values, the origin's own answers offered as no
  default; the loader-link commands for the hosts the person works in, `--links` the agent's own;
  the install's commit decided by the `commit` switch, named in the project's convention — the
  skill had named `EQUIP`, the origin's.
- Entry contract v69, *human checkpoints defer to the switches*; v70, a landed text shown again
  under `Landed`, an instruction being any text an agent acts by; v77 above. Q2 names the wake's

- *What a skill's act needs — a call, a refusal and what to do at it, a script's name — is

  homes; the user struck the reasoning tail from the proposal.
