**The forty-two decisions resumed, mostly.** The plan read them without session context and found
the shape buildable. What did not survive the reading was premises, not decisions:

- **Height is not depth.** The criterion defined height as depth in the question structure. The
  user named the conflation — two words, and in a tree two different measures — and then the
  premise: height was meant as an *abstraction* height, which the store does not measure. It left
  the slice and became an open question in the store.
- **One position cannot serve two agents.** Decision 39's single position file, with the
  per-session case deferred to teams, met the user's parallel local sessions. The position is now
  per session, registered in one temporary file, the wake taking its position from the person or
  estimating it; how sessions reach each other beyond one directory, and how a starting agent
  picks a free area, are open questions of the store.
- **The visible line is a debug display.** Decision 25's line at the head of every reply became
  what `debug=on` shows, a project setting beside the switches; the end form runs in the
  background.

**Smaller settlements:** the declared line's grammar with six added verbs; declaring again
mid-turn; `/maintain` as the fourth installed block, M1's duty; the concerns as entries alone,
`concerns.md` deleted only after the migration; `at` on every line, since a conversation is always

the person or an agent in the person's role — and helpers never.

**Resolved from the records** in the validation passes: deferred and suspect entries are never
archived; the wake has its own view; `/recall` mid-session registers nothing; the writer refuses

## What the passes kept finding

- **Terms used on the user before they were explained** — *attach*, *at*, *reply mode*, the
  pipeline itself. The user asked what each meant; every answer that followed was a plain
  restatement that should have come first. Session 28 recorded the same kind, *compressing until
  the user could not follow*. Not yet registered: a candidate entry for
  [the register](../rule-failures.md), the rule in play being `/align`'s *a new term is a decision;
  when I do not follow, go more concrete* — it fired only after the user asked.
- **A mechanism invented to meet a criterion that did not need it**: the reply mode, a checker the
  agent runs to catch the agent not running the checker. The user saw the circle in one sentence.
- **Premises taken from the parent instead of tested**: *height is depth*, and one global
  position. Each was a decision's wording carried into the plan; each fell to a question about
  what it was for.
- **Overstating a decision**: decision 39 described as *the only thing the script reads*, which it
  does not say. Corrected when the user asked when they had agreed to it.
- **An argument withdrawn on a question**: `at` optional on writes that place nothing — the user
  asked how a conversation can not be on a question, and there was no answer.
