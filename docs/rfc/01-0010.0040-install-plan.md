# Install /plan — implementation plan

**Authored:** 2026-09-06
**Last amended:** 2026-09-06

Implements [01-0010.0040](../tickets/01-0010.0040-install-plan.md): install `/plan` from Forecast Collector `plan-impl` and use it once to write the RFC for [01-0010.0050](../tickets/01-0010.0050-install-implement.md).

## Scope

Install one skill folder, `.agents/skills/plan/`. First use writes `docs/rfc/01-0010.0050-install-implement.md` with an `/impact` section. `/implement`, `/verify`, `/maintain` are not installed.

## Shapes

- Folder name `plan`, frontmatter `name: plan`. Hosts discover it the same way they discover `spec`.
- Body is Forecast Collector `plan-impl` with selected names: `/plan`, `/ticket`, `/impact`, `/align`. RFC path and paired close follow [TICKET-FORMAT](../../.agents/skills/ticket/TICKET-FORMAT.md#one-basename-per-work-item).
- No `**Pass:**` line. Collector hook/`Pass` ownership is not imported.
- `/plan` runs `/impact` and records that output on the RFC. That is the core change the entry file already states.
- No `<project-local>`. `/plan` has no project-specific fact; harness paths and `AGENTS.md` lookups are shared.

## Stages

1. Write this RFC. Record `Plan:` on the ticket.
2. Write `.agents/skills/plan/SKILL.md`. Point `AGENTS.md` and `.agents/README.md` at the install.
3. First use: `/plan` on 0050; RFC includes `/impact`.
4. Prove the ticket's boxes: catalog path, 0050 RFC exists with impact, grep of `.agents` for `plan-impl`, `AGENTS.md` installed list.

No tests. Proof is the files and `.claude/skills/plan/SKILL.md` through the existing link.

## Leave alone

`/implement`, `/verify`, `/maintain` files; pacer; `/edge`; architecture.md; source projects.
