## Shapes

### The listing script — `.agents/scripts/straw_dogs.py`

`temporary_statements.py` moved with `git mv`, so history follows the file. Same `main`, same
modes, same JSON, same exit codes: `0` clean, `1` any diagnostic, `2` usage. What changes:

- `_TAG` and `_ATTRIBUTE` read `<straw-dog until="…" ticket="…">`; the dataclass and function
  names say straw dog where they said temporary statement; the docstrings follow.
- A `<temporary\b` outside code is a diagnostic, *retired tag name*, alongside *malformed*,
  *never closed*, *unbound*.
- `Surveyed` gains `candidates`, a list beside `statements` and `diagnostics`, rendered in the
  JSON as `"candidates"`. A candidate is `{path, line, word, text}`: the record, the line, which
  word of the list matched, and the line's text stripped. The list never touches the exit
  status.

**What is guessed over.** For each record the scope names, in the order `_records_in` already
gives: skip the record whole if its path begins with `docs/tickets/`, `docs/rfc/`, `docs/spec/`
or `docs/sessions/`. Otherwise take `without_code(text)`, blank every operative straw dog's span
(the wrapper says what it is; the guess is for what nobody wrapped) and every `<installed>` block
(not this file's to edit, per the entry file, so a candidate there cannot be acted on in place),
then read line by line, skipping a line that begins with `|` and carries a moment kind followed
by ` — `. A line matching one of the words is a candidate.

**The words**, whole-word and case-insensitive: *until*, *for now*, *does not exist yet*, *no X
exists* with up to three words for X, *by hand*, *once X lands* likewise, *interim*,
*placeholder*, *nothing installs*, *nothing reads*, *nothing runs*. Fixed in the script. A
project's own words are a facet, not built.

## Stages

Each stage leaves the set green: 160 tests, `mechanisms.py --check`, `inject_rules.py --check`.

1. **The rename, whole.** `git mv` the script and its test; regexes, names and docstrings; the
   binding regex and `test_citations.py`; the four operative blocks; `AGENTS.md`'s two prose
   lines and section at v5 with the findings entry; the architecture section, landed here and
   verified; `docs/process.md:11`; the README; `maintain.md`'s parts; `/maintain`'s T1, T2, C2
   and C3. The retired-name diagnostic, written red first. The script run over the tree: four
   statements, no diagnostic, no retired name.
2. **The guess, one behavior at a time.** Tracer bullet: one word in one doc, one candidate.
   Then the skips, the folders, the exit status, the demonstration's three-and-one. Green at the
   end of every cycle.
3. **The duty and the doc.** `/verify`'s bullet, wrapped; `maintain.md`'s moments, parts and

   the guess, its count recorded in the evidence, and every candidate judged in that same pass:
   wrapped and bound where a successor is named — `maintain.md:20`'s *no installer exists yet*
   is one, bound to 01-0010 — and left where it is a claim. The script then reports the
   statements it made: the acceptance case for the whole slice is that the tree's straw dogs
   are listed rather than remembered.
