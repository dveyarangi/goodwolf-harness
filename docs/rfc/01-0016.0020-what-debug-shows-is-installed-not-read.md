## Governing decisions

  both readings behind a switch a session reads — q-0037.0009.0021, decisions 1 and 2.

  share) — q-0037.0009.0021, decisions 3 and 4.

  `inject_rules.py --set` — [01-0010.0220](../tickets/done/01-0010.0220-a-tree-carries-the-methods-text-its-settings-call-for.md);
  `docs/edge/settings.md` holds the contract.
- Both readings are debugging's, as a pair: D2 `when debug=off`, D3 `when debug=on`, their texts in
  the ticket — q-0037.0009.0021.0001.0002. No script reads `debug` — q-0037.0009.0021.0001.0003,
  moot.

1. **Rules.** D2 and D3 into `debugging.rules.md`; `debugging.md` and `/debugging` to match. Install
   with overwrite. Checks green; the entry file now says the debug text twice — authored and
   installed — until stage 2. Not committed alone.

   `local.rules.md`; reinstall local. The installer's check green; `grep debug=on` over `AGENTS.md`
   and `.agents/` finds only the debugging mechanism's own rules file, its doc, the test fixtures
   and `local.rules.md`'s settings table. Version bump and findings entry. Commit and push: stages
   1 and 2 land together.
3. **Comments and records.** The two docstrings and TODOs; `harness.md` (index-only staging);
   `docs/edge/settings.md`; q-0037.0009.0021's decision 2. The suite green — a `.py` file changed.
   Commit and push.

   the check green; a fresh session's reply read by the person shows none of the machinery.
   `--set debug=on`: D3 back, D2 gone, the next reply shows it. The tree left at `on`.
