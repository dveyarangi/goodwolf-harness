## Shapes

### The shelf

[MEETING.md](../../.agents/skills/harness/MEETING.md) as it stands at this RFC's commit, plus the
four lines *Resolved at `/plan`* landed. It is read in two occasions: before an install into a tree
with a method, and after a migration as that migration's verification. No change of shape here.

### The skill

`SKILL.md` gains:

- In the description, the occasion: *…and, in a tree that already has a method, read it and report
  what the harness would change there before anything is written*.
- A section, *A tree that already has a method*, placed before *After the first install*. It
  states, in instruction form, wording at `/implement`:
  1. **When.** The install has refused because the tree holds an entry file or an `.agents/` of its
     own — the refusal names it — or the person asks whether the harness is needed here. Nothing is
     written.
  2. **The offer.** Say what the read is and what it costs — a study by search and sampling, a
     blind run by a separate agent, on the order of half an hour and a few hundred thousand tokens
     — name the one file it would write and where, as the shelf says, and wait. Silence takes the
     offer; another place named takes that place.
  3. **The study and the report**, by the shelf, read whole first. The blind run is a separate
     fresh agent, told nothing of the harness or a measurement. The tree's git state is checked
     before and after, and the report's head says it was unchanged.
  4. **The second stop.** Show the report's main recommendations and ask one thing: whether the
     migration runs, which of its plan, in which mode. Speak of the report; do not retell it.
  5. **After.** On yes, the modes and the migration —
     [`.0020`](../tickets/01-0010.0150.0020-the-two-modes-of-taking-a-trees-method-in.md) and
     [`.0030`](../tickets/01-0010.0150.0030-the-migration-as-open-work.md), a forward pointer
     wrapped as a straw dog until they land. On no, nothing more: the report stays, the one record
     the method leaves.
  The stops, two as drafted, are wrapped as a straw dog on
  [q-0037.0006.0020.0001.0003](../questions/q-0037.0006.0020.0001.0003-does-the-meeting-need-two-stops-and-the-advise-form-at-the-second.md):
  the live meeting is their first case.
- The straw-dog count of the skill rises by two: the stops, and the forward pointer.

### The mechanism's doc

`harness.md` gains, in *Moments*, three rows instructed by the skill and the shelf: *offering to
read a tree that has a method, and stopping*; *studying the tree and writing the report*; *reading
the tree again after a migration, as its verification*. In *Install adds, uninstall removes*, the
shelf as a part. In *What it produces, and who reads it*, the report — read by the person at the
second stop and by [`.0030`](../tickets/01-0010.0150.0030-the-migration-as-open-work.md) for its
plan — and the ledger, read by q-0038.0001. The evidence records what the two trial runs refuted:
nothing in either key; eighteen places where the rules were unclear, amended.

### No script

`harness.py` is untouched. Today's refusal on an entry file already sends the agent to the skill;
the skill's new section is what it reads there. Whether a `--assess` mode ever earns its place is
left to the counts the live meetings produce.

## Flows

**A tree with a method, asked for an install.** The agent reads `SKILL.md`, whose description
names the occasion → the section → the offer, stop one → yes → the shelf, whole → the study: the
inventory with the grain of work, the readings, the sample and key, the blind agent spawned and
returned, scored → the report written at the named place, its head saying the tree is unchanged →
stop two: main recommendations, one question → yes: `.0020`; no: done.

**A tree asked whether the harness is needed, no install requested.** The same from the offer on;
the report answers the question, which is why it is written as that question's body.

**After a migration.** `.0030` reads the shelf again on the same sample and key; not this slice's
flow, but the shelf is written for it and this RFC changes nothing that would stop it.

## Limitations and follow-ups

- **Cost.** A meeting is on the order of half a million tokens and half an hour, the blind run
  included. The offer says so; nothing here makes it cheaper. A script that counts what the
  inventory counts would cut some of it, once the live meetings show which counts stay.
- **The hidden-invariants group** measures little in a tree whose code comments carry their
  reasons; run 3 said so of itself. The recipe stands; the reading of its result is the person's.
- **The report's length** doubles with the blind run's return, kept whole by the shelf. Accepted:
  it is the evidence the second reading is scored against.
- **Two sessions in one tree during a study** are the session mechanism's concern, not this
  slice's; the study reads and writes one file.
- **The stops' number** — q-0037.0006.0020.0001.0003. **The name and the readings' home** —
  q-0037.0006.0020.0013. **The front page's offer** — q-0033.0008. **The modes, the migration** —
  the sibling slices.

## Resolved at `/plan`

Counterexamples probed this pass, each against the shelf as it stood; four changed a line of it,
landed with this RFC:

- **A tree without a `docs/`.** The shelf already says the person names the place. Unchanged.
- **A tree whose documents are in a language the agent reads less well.** The report is in the
  project's language whatever it is; the two runs were Russian, and nothing in the shelf is bound
  to a language. Unchanged.
- **A tree with no pull-request list** — no remote, or a host without one. The shelf said *the PR
  list* as if it were always there. **Landed:** *and the pull-request list where the host has one*.
- **A host that gives no account of the blind run's tokens.** The shelf took the host's account
  as given. **Landed:** *where the host gives none, the ledger says so and counts what the agent's
  own account gives*.
- **A second meeting after a no**, months later: the file `0001-…` is taken. **Landed:** the
  report takes the next free number in the folder.
- **A blind agent that writes into the tree despite its rules.** Nothing checked it. **Landed:**
  the tree's git state is read before and after the study, and the report's head says it was
  unchanged; a change is the study's failure, said in the report.
- **A person who says no at the first stop.** Nothing is written, the shelf says. Unchanged.
- **The study agent reading the harness's own tree** and leaking its words. The shelf bars the
  harness's terms and phrases; run 2 leaked one phrase, run 3 none. Unchanged; the reader's check is
  criterion two.
