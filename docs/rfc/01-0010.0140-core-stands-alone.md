## Governing boundaries

- **What a leak is** — [*Core and instance*](../../AGENTS.md#core-and-instance),
  [ADR-0002](../adr/0002-core-may-not-depend-on-the-instance-half.md), the method glossary's
  *Leak*. A painted door is a record a mechanism declares — the directory or the declared file — never a
  record inside it. Instance ownership is the only exclusion, read from the enclosing block. A
  `<straw-dog>` exempts nothing; its `ticket` attribute is not a shipped reference *(`.0050`)*.
- **The align's decisions** — on the ticket, *What to build*: no exemption list; the holding list
  under a `TODO`; a resolver, not a hermetic run; folded into `mechanisms.py`, one moment row, no
  new command; a leak fails the run; `process.md` is the pacer's straw dog and its rules leave.
- **How core names a ticket** — [`.0050`](../tickets/done/01-0011.0050-shape-checked.md): in a
  binding, never a link; the body names it in words. A binding's ticket path is allowed anywhere a
  tag strips on separation.
- **The corpus grammar** — [`docs_corpus.py`](../../.agents/scripts/docs_corpus.py): citations
  through `with_citations_retargeted`, code through `without_code`, wrappers through `wrapper_of`
  and `ATTRIBUTE`, installed blocks through `INSTALLED_OPENING`. Nothing is checked that the
  grammar could not also repair.
- **The shape** — [`/mechanism`](../../.agents/skills/mechanism/SKILL.md): amending a mechanism
  runs the incept steps still live; the check is written before the thing it checks; the count of
  prior violations is recorded; story leaves the doc (R3); no index beside its records (R4).
- **The install spec** — [step 6, the shear](../spec/01-0010.0130-harness-installs-into-another-tree.md#what-the-installer-does-in-order)
  strips wrappers and refuses what this check would flag; its testing bullet names this check's
  four cases.
- **The entry contract's version record** —
  [what a version covers](../research/entry-contract-findings.md): the switch roster with its
  meanings and the straw-dog convention are covered, so both changes here bump it.

## Shapes

### What the check reads

Every file the corpus lists under `.agents/` that ends in `.md`, every `.py` there outside
`.agents/scripts/test/`, and `AGENTS.md` *(the user, 2026-09-20)*. In a `.md`, two readings of
one text, positions shared:

- **Tags are found through `without_code`**, as the lister finds them: an instance-owned block —
  `<project-local>` today, `<installed by="local">` once `.0110` retires the tag — and every
  `<straw-dog …>` opening tag. A tag in a code span or a fence is an illustration; reading it as
  a block is the dry run's ninety-line swallow.
- **Paths are found on the fence-blanked text** with the tag spans above blanked too: every
  citation the grammar recognises whose resolved record is under `docs/` — a citation elsewhere
  in the tree is the whole-tree link check's, 01-0017's — and every **path
  literal** — a token beginning `docs/` followed by at least one path character, trailing
  sentence punctuation dropped, in prose or in a code span. `docs/tickets` and `docs/tickets/`
  are one painted door. Content inside a straw dog is read; a binding never is.

In a `.py`: string literals and comments, through `tokenize`; a comment line beginning `TODO`
that names a ticket is the code form of a straw dog and its path is its binding, read as the
lister reads it and not as a citation *(resolved with the user, 1)*. A file `tokenize` cannot read is a
diagnostic, never a pass.

### Classing

Each citation or literal is one of three, and the run reports all three:

- **painted door** — equal to a row of the holding list. A directory row matches itself only:
  `docs/tickets/` is a painted door and `docs/tickets/01-0020-pacer.md` is not.
- **skipped** — inside an instance-owned block; listed with its file and line so the report shows
  what the exclusion excused.
- **leak** — everything else; each is a diagnostic naming file, line and path, and any fails the
  run. The diagnostic's subject is the citing file, as a skill's is its directory.

**The holding list** is the check's data: a dict of painted door → nothing, under one `TODO` per ticket
that removes its rows. The rows, from what core names today:

## Flows

**A change to core.** `/verify` runs the set; the check reads every core file; a new link into
`docs/` is a leak and the run fails, at home, naming the line.

**A painted door becomes declared.** `01-0017.0010` makes `record-bearing` a field; the ticket
mechanism's three rows leave the list with their `TODO`; the check reads that declaration's
records as painted doors; the diff is three lines and the report unchanged.

**A recipient.** The shear strips wrappers; the check ships and runs in the recipient's set; a
recipient's own `docs/` names are its own and nothing in core cites them, so the run is clean by
construction — what a script builds at runtime is `.0130`'s arrival test.

## Stages

Work order, not commit order: the check is written first, per the shape, and run over the tree
uncommitted; the repairs commit first (stages 3 and 4, one `IMPLEMENT` commit), then the grammar,
the check, its tests and the doc (stages 1, 2 and 5) as one more, so every commit leaves the
verification set green.

1. **The grammar.** `docs_corpus.py`: instance-owned spans, wrapper-opening spans, the path-literal
   pattern, a `.py` literal-and-comment reader. Red first through `mechanisms.check` cases.
2. **The check**, its holding list and report key. Red first: a planted link to a particular
   `docs/` document fails; a painted door passes; a link in a `<project-local>` block is skipped and
   reported; a link inside a `<straw-dog>` fails; a `TODO` naming a ticket does not; a string
   literal in a `.py` fails; the same literal in a test file is not read; a fence is not read; a
   code span is; a directory row does not match a path beneath it; the report carries three
   classes and no total. **Run over the live tree and record the count on the evidence** — the
   shape's step 4 — before any repair.
3. **The rules move**: `/verify`, `/implement`, `/maintain`, `AGENTS.md` (v11), `process.md`,
   `/skill-up`; ADR-0002 says *painted door* where it said *path convention* and its
   *Consequences* loses its two live instances, which this stage ends. `inject_rules.py --check`
   and the suite stay green; nothing parses these.
4. **The links and tokens**: the twelve wrappers bound to `.0140`, `/skill-up`'s sentence, and
   the four tokens. `straw_dogs.py` lists the wrappers from this pass gone; the count on the
   queue header moves.
5. **The doc**, through `/mechanism`'s amend steps; the check green over the doc that describes
   it; the check's commit closes the stage with the tree clean.

## Limitations and follow-ups

- **A `TODO`'s path ships until `.0130`'s shear strips it**, as the user ruled it must; the
  rule is on `.0130`'s ticket, and this check treats the path as a binding from day one.
- **The check reads `AGENTS.md` whole**, its local blocks skipped like any other; the entry file
  is core and ships, so a leak there is the same leak.
- **Story stays.** The grading paragraphs still tell their story with the ticket named in words;
  moving story to evidence is R3 at the ring's `/maintain`, not this slice's.
- **`.agents/README.md` is read** like any `.md` under `.agents/`; it cites nothing under `docs/`
  today.
- **A recipient's `installed by="local"` block** is skipped by tag before the tag exists; the
  pattern costs one alternation and is ADR-0002's word.

## Resolved at `/plan`

1. **Fences are illustrations; code spans and prose are claims.** The format shelf backticks
   every path, so a code span is how a claim is written here.
2. **A directory row matches itself only.** A path beneath a painted door is a document.
3. **The grammar lives in `docs_corpus.py`**, beside the citation and binding grammars the mover
   rewrites, so the lister and the check read one text the same way.
4. **`.py` literals are read through `tokenize`**, so a comment's `file:///docs/…` illustration
   with no path character after the slash is not a token.
5. **The report shows what was skipped**, not only what leaked: an exclusion nobody can see is
   the review this check replaces.
6. **`/maintain`'s local block loses the verification sentence** rather than repointing it: where
   the set lives stopped being a local fact.
7. **Tags through `without_code`, paths through the fence-blanked text.** The corpus already
   makes that cut for the lister; the dry run showed why it is not optional.
8. **The process document's two sections become pointer lines under their headings**, not
   deletions: a pointer is not a second home, and thirty fragments across live and closed records
   keep resolving without a rewrite of the instance half.
