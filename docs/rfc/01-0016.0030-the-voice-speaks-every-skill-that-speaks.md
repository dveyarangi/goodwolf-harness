## Governing boundaries

- **A project's own answers live in its local file** and reach a file only as the local block, last
  at its anchor (R7). The voice is such an answer.
- **A rule reaches every file of a group** by a row whose target is a path pattern and whose anchor
  is the heading a member holds ([Installed blocks](../architecture.md#installed-blocks)); the local
  file is a source like any other.
- **A project fact never stands in core** (L10, the leak check): no core text names this tree's
  voice.
- **What is said at a moment is the speaking skill's**; how it is said is the voice's
  (q-0037.0009.0021.0002, decisions 3 and 8).
