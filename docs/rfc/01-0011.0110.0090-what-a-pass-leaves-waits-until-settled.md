## Governing boundaries

- **The marks are the maintenance mechanism's one record**, written only by `maintain.py`, read by
  its check at every pass; a malformed row fails the check
  ([MARKS-FORMAT.md](../../.agents/skills/maintain/MARKS-FORMAT.md)).
- **What waits is a fixed field a script reads, never prose a model reads**, shown by the wake only
  while it holds anything, put to the person by a rule the maintenance mechanism installs in
  `/recall`, gone when settled, not when read (q-0037.0010.0009.0009, decision 3).
- **Scripts enumerate and transform, and decide nothing**
  ([Responsibilities](../architecture.md#responsibilities)): the script lists what waits; the agent
  puts it to the person.
- **A mechanism's rule reaches a skill only as an installed block** (R5, R8).

**Hidden edges.**

- **A wait is no property of a mechanism's level.** A re-check rewrites its mark whole, and a wait
  found across mechanisms has no level; so a wait stands in its own table, untouched by any mark,
  and goes only when removed. Its *where* names a mechanism, or the tree for one found across
  them.
- **The reader refuses a third table today** (*a third table; the marks hold two*): it reads one
  with the waits' header, and still refuses a fourth. A file with two tables waits on nothing, so
  this tree's marks need no rewrite and no recipient a migration.
- **The wake's section helper writes `(none)` under an empty heading**, so an empty section reads
  as present; this section is added only when something waits.
- **Circular import.** `maintain.py` imports `mechanisms.py`, which imports the store; the wake
  imports `maintain` inside its function, as the path imports tickets and the product script.
- **A cell's text.** A decision holding `|` or a line break is refused by the call that writes it.
- **Bounded.** The wake is read at every start; the section shows at most five lines and *and N
  more*.

**Leave alone.** Dueness and fingerprints; the three outcomes; the files table; the scheduled
pass and its sweep — 01-0011.0110.0100.

## Stages

Each stage ends green; the tests run, scripts changing.

1. **The waits, red first** in `test_maintain.py`: two `--wait` calls write two rows and `--check`
   lists both, numbered; a `--mark` of a level leaves them as they were; `--settle 1` removes the
   first and leaves the marks and their fingerprints as they were; settling a number not there
   refuses; a decision holding `|` refuses, and so does a *where* that is neither a declared
   mechanism nor `tree`; a file with two tables waits on nothing; a malformed waits row fails the
   check, a fourth table too. Then `maintain.py`.
2. **The wake**, in `test_questions.py`: a tree whose marks hold a wait shows the section with it,
   after the path; one with none shows no heading; six waits show five and *and 1 more*. Then
   `questions.py`.
3. **The instructions**: `MARKS-FORMAT.md`, the line beside F4, the doc's record paragraph and
   moment row, M3 in the rules file and installed; `inject_rules.py --check` and
   `mechanisms.py --check` green.
4. **Read live**: a subagent with none of this session, started as a session on this tree with one
   wait written by `--mark`, writes its first report under `/recall`; a judge who did not build it
   reads whether the wait is put to the person as a decision. The wait is then settled and the
   wake read again for no section.
