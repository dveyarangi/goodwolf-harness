# An update never replaces a file the project owns — implementation plan

- **record of** what it intends to become

**Authored:** 2026-10-13

Implements [01-0035.0030 an-update-never-replaces-a-file-the-project-owns](../tickets/01-0035.0030-an-update-never-replaces-a-file-the-project-owns.md).

## What governs it

The harness mechanism's doc, `.agents/mechanisms/harness/harness.md`: every refusal writes
nothing; an edit in core is refused unless `--overwrite`, which replaces and reports.
[Interruption and recovery](../architecture.md#interruption-and-recovery): detected interference
is a failure, never authority to overwrite.

## What breaks it today

`_refuse_unless_updatable` compares only the files the previous ref shipped. A path the new ref
adds is never looked at: `_write` skips a file that already holds what ships and writes over any
other, so a file of the project's own at that path is replaced silently.

## The change

`_refuse_unless_updatable` reads one more set beside the edited core files: the paths the new ref
adds — in the shipment, not in the previous ref — that the tree already holds with other content
than ships, read as `_holds` reads it. They join the same refusal and the same `--overwrite`:
refused naming the first, or replaced and reported among `replaced`. A tree announcing no ref has
no previous to compare with, and `--overwrite` already replaces every core file there; it stays as
it is.

## Stages

1. **Red.** In `test_harness.py`'s `AnUpdate`: the source adds a skill at a path where the target
   holds its own file; `--update` is refused naming that path with the target's bytes as before;
   `--update --overwrite` replaces it and reports it in `replaced`; a target holding exactly what
   ships there is neither refused nor reported. Today the first is written over.
2. **Green.** The set read in `_refuse_unless_updatable`.

## Impact

**Impact.** `_refuse_unless_updatable`; update tests. **Hidden edges.** The new path read through
`_holds`, so a file carrying only the recipient's own installed blocks counts as holding what
ships. **Leave alone.** The install path, refused on any shipped path present. **Recommendation.**
Proceed.
