## Shapes

### The listing script — `.agents/scripts/straw_dogs.py`

`temporary_statements.py` moved with `git mv`, so history follows the file. Same `main`, same
modes, same JSON, same exit codes: `0` clean, `1` any diagnostic, `2` usage. What changes:

- `_TAG` and `_ATTRIBUTE` read `<straw-dog until="…" ticket="…">`; the dataclass and function
  names say straw dog where they said temporary statement; the docstrings follow.
- A `<temporary\b` outside code is a diagnostic, *retired tag name*, alongside *malformed*,
  *never closed*, *unbound*.
- A third mode, `--guess PATH [PATH ...]`, beside listing and `--remove`. It prints
  `{"scanned": […], "candidates": […]}` and exits `0` whatever it finds; a candidate is
  `{path, line, word, text}`: the record, the line, which word of the list matched, and the
  line's text stripped. The plain listing does not guess: the entry file's own section carries
  *until* twice, honestly, and a guess folded into every `/maintain` pass would re-report it and
  every other honest tell forever. Guessing is run over a declared scope by whoever is judging.

**What is guessed over.** For each record the scope names, in the order `_records_in` already
gives: skip the record whole if its path begins with `docs/tickets/`, `docs/rfc/`, `docs/spec/`
or `docs/sessions/`. Otherwise take `without_code(text)`, blank every operative straw dog's span
(the wrapper says what it is; the guess is for what nobody wrapped) and every `<installed>` block
(not this file's to edit, per the entry file, so a candidate there cannot be acted on in place),
then read line by line, skipping a line that begins with `|` and carries a moment kind followed
by ` — `. A line matching one of the words is a candidate.

**Code.** `_records_in` also yields `*.py` under the paths given. A code record is read for
lines carrying `TODO`: one that names a `docs/tickets/…` path is a statement with that ticket as
owner and no `until`, subject to the same *unknown owner* diagnostic; one that names none is a
candidate with word `TODO`. Tags are not looked for in code; the word list is not applied to
code. The four harness folders hold no code and the skip does not arise.

**The words**, whole-word and case-insensitive: *until*, *for now*, *does not exist yet*, *no X
exists* with up to three words for X, *by hand*, *once X lands* likewise, *interim*,
*placeholder*, *nothing installs*, *nothing reads*, *nothing runs*. Fixed in the script. A
project's own words are a facet, not built.

### The corpus reader, the mover and the injector — `docs_corpus.py`, `move_doc.py`, `inject_rules.py`

  text; a scope with none reports an empty list; the exit is `0` either way; the plain listing
