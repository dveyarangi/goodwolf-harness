## Shape

**The roots.** The purpose root is the live root whose words are *What is this project for?*, the
structure root the one whose words are *How is this project built?*. Both words stand in
`product.py` beside a `TODO` bound to q-0037.0018.0011: the store's shelf holds them too until each
mechanism declares the root it owns. A store with neither root finds nothing that needs it.

**Reading a row.** Beyond its id and name, an answer row's last cell, *waits on*: empty for a
decided answer; for an undecided one, the straw dog it holds, read by `docs_corpus.bindings_in`,
the reader every binding scan uses.

**Diagnostics** — something is broken, the check fails, exit 1:

- an answer row with no `**A<n> <name>**` lead, an id written twice (from `.0010`);
- a live question's own link naming a reference no answer holds;
- a live question's own link quoting a name other than its answer's;
- a row whose *waits on* binds a question outside the purpose root, or one the store does not hold;
- a row whose *waits on* holds something and binds no question — undecided, with no binding.

**Findings** — something is missing, reported, never failing:

- an orphan: an open question under the structure root, the root itself aside, whose effective
  link is none — a question stating `derived` is no orphan;
- an unrealized answer: a decided answer whose coverage is absent;
- a purpose question no row names: an open question under the purpose root, the root aside, that
  no row binds, neither it nor an ancestor below the root.

Only a question's own link is held to the answers, so a broken link is reported once, where it is
written. Closed questions in `done/` are history and are not checked; coverage still reads them.

The report gains `findings`, each `{record, line, finding}`, as the store's check reports its own.
No document, nothing reported and exit 0, as before.

## Limits

A suspect or deferred question is read by its state, as coverage reads it. Questions closed in the
live store are not orphans. A pain's measure stays out (q-0037.0018.0004).
