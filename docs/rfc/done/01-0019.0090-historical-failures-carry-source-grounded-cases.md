## Scope and choices

The [accepted scope](../../questions/q-0037.0012.0009.0001-how-is-a-recorded-rule-failure-replayed-as-a-test-against-the-amended-rule.md#where-it-stands)
owns each choice: a folder under `docs/cases/` keeps each occurrence's case and relevant exact
source records; logical chat/message identifiers and original record hashes preserve provenance
without making a local path a dependency. The case states the pre-failure situation, observed
failure, expected behaviour and an inspectable check. Evidence gaps stay with the register's
occurrence, preserving whatever attribution the source establishes.

## Stages

1. Extract the original recall omission from Codex chat `01a17792-eb83-75d1-9fc4-dedb2eed8589`.
   Preserve its source-provided instructions and relevant pre-failure public messages/tool results;
   private reasoning and unrelated later turns are excluded.
2. An independent reader compares case and source and tests the check on both the recorded bad
   response and a source-supported compliant specimen, labelled as authored where applicable.
   The check rejects the failure and accepts the compliant specimen. Bulk extraction starts after
   a pass; these checks do not run an instruction-effect experiment.
3. Enumerate every original entry and repeat, match the triggering event in available original
   transcripts, extract each recovered case, and add a case link or explicit gap to that occurrence.
4. Verify quoted text, attribution and source hashes; independently audit coverage and source
   selection. Run the project's verification set and close this work only when its criteria hold.

## Impact

Case evidence and register links change; the accepted one-case validity gate is preserved.

## Hidden edges

Copied context is not a second observed failure. A reopened chat can contain several models;
model attribution follows the relevant message/turn, with synthetic or absent values left unknown.
An original transcript can expose an event not faithfully described by the later register;
source discrepancies are preserved and reported rather than silently rewriting history.

## Leave alone

Core code, execution tooling, standing instructions, existing case-run results and live capture.

## Recommendation

Proceed. The first actual source case tests the extraction shape before applying it to the corpus;
no new runtime, persistent extraction mechanism or instruction-effect experiment is introduced.
