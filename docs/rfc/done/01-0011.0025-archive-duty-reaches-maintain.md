### The maintainer — `.agents/scripts/tickets.py`

    uv run --offline --no-project python .agents/scripts/tickets.py --check

One mode; a bare invocation prints usage and exits 2, as the others do. The report mirrors
`mechanisms.py`: JSON with `records` (each live ticket with the header it read), `diagnostics`
(one per violation: file, line, and the rule in the shelf's words), and `skipped` (a record
that could not be read, with why). Exit 1 on any diagnostic or skip, 0 otherwise. Writes nothing.

Reads through `docs_corpus.corpus(root)`: the header and sections of every file under
`docs/tickets/` that is not under `done/` and is not `README.md`; the names only of every file
under `docs/rfc/`, `docs/rfc/done/` and `docs/tickets/done/`, for pairing. The header reader
takes the bullet list at the first non-blank line after the H1 and stops at the first line that
is neither a bullet nor an indented continuation; a `**Status:**` further down is prose. Links
are resolved through `citations` and `cited_record`. One sentence means no sentence boundary
inside the value — a `.`, `?` or `!` followed by whitespace and a capital letter or a backtick —
so a trailing form is never judged and an abbreviation convention is not invented.

What it never checks, per `/impact`: a status against a folder, a dependency's state, an
outcome's quality, anything under `done/` beyond an RFC's basename.

## Limitations and follow-ups

- **A `Done` ticket in the live folder is not reported.** It is `.0030`'s eligibility question.
  The maintainer would see it and says nothing; the listing that lands next says it.
- **Outcome length is a line-level rule with one sentence-terminator convention**, stated in the
  shelf. An outcome quoting a sentence-ending abbreviation would misfire; none exists today, and
  the rule is amended when one does rather than pre-empted.
- **The queue is still hand-copied** until `.0040`, and this slice's stage rule makes the copy
  slightly worse before it is derived: an outcome cut to one sentence is copied by hand again.
- **`/plan`'s block sits at the end of a body with no headings.** When `/plan` is declared under
