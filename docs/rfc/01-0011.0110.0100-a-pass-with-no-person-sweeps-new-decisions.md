## Governing boundaries

Each stands on a line of the question's `Where it stands` or a decision of it.

- **The sweep crosses mechanisms** (decision 1): what landed is read from the history since the
  mark, not from any mechanism's dueness.
- **Since the last pass is one tree-wide mark** (decision 2): the commit the decisions were last
  swept through, moved only by the pass that closes the sweep; a failed pass leaves it where it
  was.
- **The instruction is `/maintain`'s**, a section for a pass with no person; the host's task is one
  line (decision 4).
- **Below the dial a pass repairs by subagents; in another running session's work it tells that
  session; at or above the dial it leaves a question asking the person** (M2; the store's `ask`),
  placed by the store's own rule for a new question (Q1).
- **What a script can tell, a script tells**: the listing of what landed is the script's; whether a
  text contradicts it is the agent's.

## Impact

**Must change.**

- `.agents/scripts/gw/maintain.py`: the marks' tree-wide row, `tree` at the level `decisions`,
  whose fingerprint cell holds the commit swept through; `--landed`, listing what landed since that
  commit and naming the commit it read through; `--mark tree decisions <outcome> <commit>`, writing
  that commit.
- `.agents/scripts/gw/mechanisms.py`: a mechanism may not take the slug `tree`.
- `.agents/scripts/gw/test/test_maintain.py`: the cases below.
- `.agents/skills/maintain/MARKS-FORMAT.md`: the tree-wide row.
- `.agents/skills/maintain/SKILL.md`: a section, *A pass with no person*.
- `.agents/mechanisms/maintain/maintain.md`: the record's tree-wide row; the moment of a pass with
  no person; its authority.
- The host's scheduled task, outside the tree: cut to one line — shown to the person before it is
  written.

**Must verify.** This tree's marks read with and without the row; `--landed` on this tree lists
the day's decisions; the verification set green.

**Hidden edges.**

- **The mark writes the commit the listing read through.** A decision another session commits
  between `--landed` and `--mark` stands past that commit, so the next listing carries it; the
  pass's own repairs land past it too and are listed next time, to be found already agreeing.
- **A commit the history lacks reads as no row** — after a rebase, a squash, a shallow clone, or a
  tree with no history — and the listing says so; `--mark tree` writes over it. It is never a
  diagnostic: one would refuse every mark of the tree, and the marks have no other writer.
- **With no row, or an unreadable one**, `--landed` lists the last seven days and says so — the
  window the session rows keep. A reversible choice of this plan, named to the person.
- **`tree` is no declared mechanism**: a mark of a level keeps the row by name, as `_kept` would
  otherwise drop it; the check does not list it as undeclared; in a recipient, whose clock holds
  none of core's mechanisms, the row is the recipient's own and is accepted. The writer's sort
  orders the row after every level.
- **What landed**, from `git diff --find-renames <commit> <head>` over the store, the rules files
  (`local.rules.md` among them), the entry file, the architecture and the ADRs:
  - an entry whose `## Decisions` gained an item or had one changed — a line that only gains its
    `→ <home>` is not a change of the decision;
  - an entry whose state became closed;
  - a rules file, the entry file, the architecture or an ADR changed;
  - an entry moved to `done/` unchanged is no landing.

  A commit's subject is never read: it is the project's convention.
- **The script runs git only when a tree-wide row stands or `--landed` is asked**; `--check` and a
  level's mark run none, as today.
- **A wait it leaves** goes to the open question that already holds it, else is opened where Q1
  places a new question; `ask` on it. A second pass finding the same drift finds the question
  asking already, and `ask` writes nothing.

**Leave alone.** Dueness and the mechanisms' levels; the store; `/recall`.

## Stages

Each stage ends green; the tests run, a script changing.

1. **The row and the listing, red first** in `test_maintain.py`, on a fixture repository with
   commits, each test marked as one that spawns a process:
   - `--mark tree decisions repaired <commit>` writes that commit; a level's mark keeps the row,
     sorted after the levels; the check does not list it as undeclared; in a recipient it is
     accepted;
   - a row whose commit the history lacks reads as none, the check passes, and `--landed` says so
     and lists seven days; with no row, the same;
   - `--landed` after commits that add a decision item, change one, only add a `→` to one, close an
     entry, move an unchanged entry to `done/`, and change a rules file, `local.rules.md` and a
     ticket lists the added, the changed, the closed and the two rules files, and nothing else,
     naming the head it read through;
   - `--landed` writes nothing, and called twice without a mark lists the same — a failed pass
     leaves the mark where it was;
   - a decision committed after `--landed` and before the mark is listed by the next `--landed`.

   Then `maintain.py`; `mechanisms.py` refuses a mechanism declared as `tree`.
2. **The section, tried before it lands**: on a git clone in the scratchpad of the commit carrying
   stage 1, a decision is committed that contradicts a text in another mechanism, below the dial,
   and another at or above it; a subagent with none of this session, told it is the scheduled pass
   and given only the proposed section beside the clone's `/maintain`, runs the pass there. A judge
   who did not build it reads the clone after: the first text repaired, the second left as a
   question asking the person, the mark at the commit read through. Then the section, the marks
   format, the doc's record, moment and authority land; `mechanisms.py --check` green.
3. **The host's task**, shown to the person and cut to one line on their word.
4. **Read live**: the scheduled task run now on this tree, its session left to finish; its
   commits, the questions it left asking and the next session's wake read by a judge who built
   none of it.
