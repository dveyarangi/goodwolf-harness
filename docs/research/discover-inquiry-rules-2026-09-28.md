# Discover report: what organises and reorganises a held set of questions

## Families

Notation: [H]/[M]/[L] = high/medium/low confidence in the claim as stated. (E) = rests on evidence I can point to (a text, a case, a system that exists and behaves so); (P) = rests on argument or reconstruction only. Where a family is silent on a point, I say so rather than fill it.

### 1. Erotetic logic (Belnap–Steel, partition semantics, Wiśniewski's Inferential Erotetic Logic, inquisitive semantics; with van Fraassen/Bromberger on why-questions)

**Mapping.** The inquiry is a *principal question* plus a tree of *auxiliary questions* related to it by logically defined relations (evocation, erotetic implication, containment); an "erotetic search scenario" is exactly a labelled tree of such questions ending in direct answers to the principal one. [H] (E) — [Wiśniewski, Erotetic Search Scenarios, Synthese 2003](https://link.springer.com/article/10.1023/A:1022983325118); [intro to IEL](https://awisniew.web.amu.edu.pl/dydaktyka/Unilog/2.%20Inferential%20Erotetic%20Logic.pdf).

1. **Arising.** Three relations, all defined over *answer sets*, not presuppositions alone. *Evocation*: a set of declaratives X evokes Q when X entails Q's presupposition (some direct answer is true) but entails no direct answer — a question arises from what is known when it is sound and not yet settled. *Erotetic implication*: Q together with X implies Q1 when (a) any answer to Q plus X guarantees Q1 has a true answer, and (b) every answer to Q1 plus X narrows the answers to Q. That "narrowing" clause is the family's definition of one question *serving* another. Belnap's *containment*: Q1 contains Q2 if every direct answer to Q1 entails some direct answer to Q2. So a question's place is derived from the difference between what is known and the answer set wanted — not from a strategy for the parent and not from presuppositions per se. [H] (E)
2. **Skipped question.** A question with an unestablished presupposition is *unsound relative to X*; Belnap–Steel treat a question with a false presupposition as having no true direct answer and allow only a *corrective answer* (denying the presupposition). In IEL the scenario cannot include an unsound question, so the skipped question shows up as a soundness failure: the presupposition must first be obtained (as an answer to a prior question) — insert above. There is no "proceed conditionally" in the core logic; the epistemic ESS variant ([Epistemic Erotetic Search Scenarios, LLP 2018](https://apcz.umk.pl/LLP/article/view/LLP.2018.010)) lets the agent's knowledge state be the thing updated. [H] (E)
3. **Descend or hold.** A scenario tells "what auxiliary questions should be asked and when" — the *when* is: an auxiliary question is asked only when erotetically implied by the current question and current knowledge. No commitment below can be undone by a higher answer, because the tree only descends from the principal question and every node is sound given its ancestors. Going up is not defined; the logic is asymmetric. [H] (E)
4. **Identity.** Belnap–Steel: two questions are equivalent iff they have the same set of direct answers. Groenendijk–Stokhof partition semantics: same question iff same partition of the logical space; Q1 entails Q2 iff Q1's partition refines Q2's. Inquisitive semantics: same issue iff the same set of information states resolve it. Wording is irrelevant; a rewording with a different answer set is a different question and the old one simply stays (no operation on it). [H] (E)
5. **Dropping and postponing.** A question already answered by X is not evoked (it is "self-rhetorical"); one whose presupposition X refutes is unsound. Both drop by definition. Postponing is not a concept in the logic — there is no notion of acting meanwhile. A question made irrelevant by another's answer is one whose answer is now entailed: it stops being evoked. [H] (E)
6. **Ascent stops.** The principal question is *given*; the logic has no rule for choosing it and no ascent relation. (Wiśniewski's Socratic-proof calculi go from questions to questions, but always downward.) [H] (E)
7. **Well-posedness.** A question is fit to be worked when it is *sound* (its presupposition holds in the knowledge base), *informative* (no answer entailed), and *safe* if its presupposition is logically valid vs *risky* if not. Van Fraassen's why-question adds a contrast class and a relevance relation: a why-question "arises" only if the topic is true, the contrast alternatives false, and a relevant true answer exists — otherwise it is *rejected*, not answered. [H] (E) — [van Fraassen, The Scientific Image 1980, ch. 5]
8. **Failure catalogue.** Unsound question (false presupposition; from inside: every answer feels wrong; detected by finding a corrective answer); self-rhetorical question (already answered); an "implied" question that fails the narrowing clause (working it settles nothing about the parent); Bromberger's *p-predicament* (one cannot think of a correct answer though there is one) vs *b-predicament* (the question is unanswerable in principle from the inquirer's concepts) — the second is a symptom that the question must be reformulated, not answered. [M] (E) — [Bromberger, On What We Know We Don't Know 1992]
9. **Ladder.** The described process is *past* what this family formalises: IEL handles the descending tree with fixed answer sets and is automated ([ACM TOCL 2017](https://dl.acm.org/doi/10.1145/3056537)); it has nothing for open answer sets, ascent, or postponement. [H] (P)
10. Confidence as marked.

### 2. Hintikka's interrogative model of inquiry

**Mapping.** Inquiry is a two-player game: the Inquirer builds a tableau by deductive moves and by *interrogative moves* (questions put to an oracle, "Nature" or a second party), aiming to answer a *principal question* through *operative questions*. [H] (E) — [Hintikka, Socratic Epistemology 2007, NDPR review](https://ndpr.nd.edu/reviews/socratic-epistemology-explorations-of-knowledge-seeking-by-questioning/); [interrogative model as theory of argumentation](https://philpapers.org/rec/HINTIM).

1. **Arising.** Operative questions arise exactly as instantiation steps arise in a tableau proof: Hintikka's central thesis is that the strategic rules of questioning are the strategic rules of deduction (choose which existential to instantiate ≈ choose which wh-question to ask). A question's place is derived from a strategy for the principal question, constrained by presupposition. [H] (E)
2. **Skipped question.** The *presupposition rule* is definitory: a question may be asked only when its presupposition already stands in the tableau (for a wh-question, the existential claim; for a yes/no question, the trivial p∨¬p). Asking "which x?" before "is there an x?" is an illegal move; the repair is to obtain the presupposition first — insert above. [H] (E)
3. **Descend or hold.** Definitory rules say what is permitted; *strategic* rules say what is advisable and, Hintikka insists, can only be evaluated over whole strategies, not single moves — so there is no move-local rule for "descend now". Answers received may later be *bracketed* (put in doubt) and unbracketed; a bracketed answer's consequences lose their standing — that is the model's account of commitments below undone by a later finding. Going up is not a move; the principal question is fixed. [H] (E) on rules; [M] (E) on bracketing.
4. **Identity.** Inherits the erotetic notion (same presupposition and answer set). No merge operation; a reworded question is a new tableau move. [M] (P)
5. **Dropping and postponing.** A question whose answer is already in the tableau is useless (a wasted move). No postponement mechanism; the closest is choosing a different branch of the strategy first. [M] (P)
6. **Ascent stops.** The principal question is given by the inquirer; Hintikka repeatedly treats yes/no principal questions and "big" questions as reconstructions of an activity, not as chosen by rule. The *range of attention* (what individuals are in play) limits which questions are askable at all. [M] (E)
7. **Well-posedness.** A question is askable when its presupposition is established and its answer would be a *conclusive* answer (the answerer's reply lets the inquirer know what is being referred to — the "conclusiveness condition"). [H] (E)
8. **Failure catalogue.** Asking with an unestablished presupposition (the fallacy of many questions, redefined as a definitory violation); *petitio principii* reconstructed as asking the principal question as if it were an operative one; *ignoratio elenchi* as answering a different principal question; trusting an oracle answer that should be bracketed. Detection: tableau inspection. [M] (E) — Hintikka, "The Fallacy of Fallacies" 1987.
9. **Ladder.** The described process is the mature form as far as *descending* goes; the model refuses to say anything about ascent or about the second party as a decider (Nature answers, it does not decide). [H] (P)

### 3. Questions Under Discussion in discourse and dialogue systems (Roberts; Büring; Ginzburg's KoS; Larsson's issue-based dialogue management)

**Mapping.** A discourse maintains a partially ordered stack of accepted questions; every move must address the top question or raise a subquestion of it; questions are pushed when accepted, popped when answered or abandoned, and *accommodated* when a move presupposes a question nobody raised. [H] (E) — [Roberts 2012](https://philpapers.org/rec/ROBISI-6); [Larsson 2002 thesis](http://www-gth.die.upm.es/research/documentation/referencias/Larsson_Tesis.pdf).

1. **Arising.** Roberts: a *strategy of inquiry* is a set of subquestions whose complete answers jointly entail an answer to the superquestion (question entailment in the partition sense) — a question's place is a strategy for its parent. Ginzburg: a question q1 *influences* q2 (asking q1 helps resolve q2) — the dependence relation is what licenses raising q1 while q2 is max-QUD. Larsson: questions come from a *plan* (an agenda of questions to be resolved for a task). [H] (E)
2. **Skipped question.** *Question accommodation* (Larsson): when an utterance arrives that answers no question on the stack, the system searches the current plan (local accommodation) or all plans (global accommodation, which also recognises which task is being pursued) for a question the utterance would answer, and pushes it — insert above, silently. Büring's d-trees: a contrastive-topic marking signals an unasked superquestion, which the hearer reconstructs. Ginzburg: an utterance that cannot be integrated triggers a *clarification request* — a question about the utterance, i.e., a controlled ascent. [H] (E)
3. **Descend or hold.** Roberts' relevance constraint: a move is relevant only if it addresses the maximal QUD; you may descend to a subquestion only as part of a strategy for the top. Ginzburg's QSPEC: a move must be "about" or "influence" max-QUD. Larsson adds *re-raising*: a question popped prematurely can be raised again. Commitments below: Ginzburg's *QUD downdate* removes a question once FACTS resolve it; nothing in these systems retracts an answer when a higher one changes — they are monotone on facts (Larsson's negotiation extension, "issues under negotiation", holds alternatives open). Up and down are not alike: going up is accommodation or clarification, never a free move. [H] (E)
4. **Identity.** Partition semantics: same question iff same partition. Larsson: same issue iff same semantic question object; a paraphrase merges into the existing stack entry; a question with a different partition is a new one and the old stays until resolved. [H] (E)
5. **Dropping and postponing.** Roberts: a question is popped when answered *or when the participants accept it as unanswerable* — abandonment is a joint move. Larsson: an issue can be pushed down by a more urgent one and re-raised; the plan supplies what to do meanwhile (ask the next question in the plan). A question made irrelevant: Ginzburg downdates any question the new facts resolve, not only the one addressed. [H] (E)
6. **Ascent stops.** Roberts is explicit: the top of every stack is the *Big Question*, "What is the way things are?"; all domain goals are subquestions of it. Larsson: the top is the task plan the user is recognised to be pursuing (chosen by the user, recognised by accommodation). [H] (E)
7. **Well-posedness.** A question is workable when its presupposition is in the common ground (or accommodable) and it is *accepted* by the participants (Roberts distinguishes raising from accepting). Ginzburg: a question must be integrable into the DGB; if not, clarification first. [H] (E)
8. **Failure catalogue.** Irrelevant move (does not address max-QUD; detected by failed integration); unaccommodatable answer (no plan contains a matching question → clarification/rejection); stale QUD (question resolved but not downdated); ambiguous accommodation (several plans match — Larsson requires disambiguation). [H] (E)
9. **Ladder.** The described process is the mature form of this family; it runs today in deployed dialogue managers ([Talkamatic 2024](https://arxiv.org/pdf/2407.02917)). The family is *narrower* than the shape: it has no rule for "worth holding" beyond the plan, and no ascent beyond accommodation. [H] (E)

### 4. Formal dialectic and commitment-based dialogue (Hamblin; Mackenzie; Walton–Krabbe; pragma-dialectics)

**Mapping.** Inquiry is a rule-governed dialogue game in which each party keeps a *commitment store*; questions and "Why?" challenges are moves whose legality depends on what the other has already conceded, and fallacies are illegal moves. [H] (E) — Hamblin, *Fallacies* 1970 ch. 8; Walton & Krabbe, *Commitment in Dialogue* 1995.

1. **Arising.** A "Why S?" challenge arises only against an S in the challenged party's store; a question arises from a commitment, not from a strategy. Pragma-dialectics: the *confrontation stage* fixes the difference of opinion; sub-standpoints arise from the argumentation structure (multiple, coordinative, subordinative). [H] (E)
2. **Skipped question.** Mackenzie's DC forbids "Why S?" unless S is in the hearer's commitments, and forbids a question whose presupposition is not conceded; a violation is the *fallacy of many questions*. Reconstruction of *unexpressed premises* (pragma-dialectics) is the standard way a skipped question is made explicit: it is inserted as a premise the arguer is held to. [H] (E)
3. **Descend or hold.** Mackenzie: a challenge must be answered in the next move (a stack discipline); a party may retract, but retraction has *stability adjustment* rules in Walton–Krabbe (retracting a concession forces retraction of what rested on it). Walton's *dialectical shift*: a licit shift (persuasion → information-seeking to settle a fact) is descent; an illicit shift (persuasion → negotiation) is the family's diagnosis of "the subject has moved". Up and down are not symmetric: descent is licensed by a challenge; ascent is a shift and needs both parties. [M] (E)
4. **Identity.** Pragma-dialectics' *maximally argumentative interpretation* reconstructs what standpoint is really at issue; two wordings are the same standpoint if they commit the party to the same proposition under that reconstruction. [M] (E)
5. **Dropping.** "No commitment" is a legal answer; a challenge to a retracted statement lapses. Walton's *dialectical relevance*: a question that cannot bear on the global issue of the dialogue may be refused. [M] (E)
6. **Ascent stops.** At the *thesis* fixed in the confrontation/opening stage, by the parties' agreement; the family has no criterion other than agreement, and treats reopening it mid-dialogue as a shift. [H] (E)
7. **Well-posedness.** A question is legal when its presupposition is conceded and it is *dialectically relevant*; pragma-dialectics adds the *freedom rule* and *burden-of-proof rule* (a standpoint must be defended when asked). [H] (E)
8. **Failure catalogue** (the richest of any family): many questions (unconceded presupposition); begging the question (Mackenzie: a circular challenge chain — detected by tracing the chain); ignoratio elenchi (answering a different question); red herring / straw man (shift of subject or standpoint); evading the burden of proof; illicit dialectical shift; "wrenching from context". Each is defined as a rule violation and detected by inspecting the record of moves. [H] (E)
9. **Ladder.** The described process, with one party mostly alone, is a *degenerate* instance: this family's rules need two stores. Its mature form is the two-party protocol; the single-party form loses the challenge mechanism that generates questions. [M] (P)

### 5. Aristotelian dialectic and the scholastic *quaestio*

**Mapping.** Inquiry into a subject proceeds through an ordered sequence of question-types (whether it is, what it is, whether it has a property, why), and a disputed question is worked by stating objections, a counter-authority, a determination that *distinguishes*, and replies. [H] (E) — *Posterior Analytics* II.1 (89b23); *Topics* I.11, VIII; Aquinas, *Summa*; Abelard, *Sic et Non*.

1. **Arising.** *Post. An.* II.1: four questions — the *that* (hoti), the *why* (dioti), *whether it is* (ei esti), *what it is* (ti esti) — and an order: we ask why only after knowing that; what it is only after that it is. A question's place is derived from presupposition, fixed in advance by type. The scholastic ordering of articles reproduces this (an sit → quid sit → quomodo sit). Questions also arise from *clash of authorities* (Abelard) or of *endoxa*. [H] (E)
2. **Skipped question.** The order is the detector: an inquiry into *why* that lacks the *that* is malformed. *Topics* VIII.7: when a question asked "is more than one", the answerer must *divide* it ("in one sense yes, in another no") — the *distinguo*. Insertion above: the prior question-type must be settled; it is not abandoned below but re-attached under the distinction. [H] (E)
3. **Descend or hold.** The questioner's art (*Topics* VIII.1) is to obtain premises *before* revealing the conclusion they serve — descent is strategic concealment; the answerer's art is to grant only what is endoxon and to demand the division when a premise is ambiguous. Commitments below: in the *quaestio* form the *respondeo* re-reads every objection through the distinction, so lower answers are re-scoped, not undone. [M] (E)
4. **Identity.** Two questions are one if they resolve to the same *problema* under the same sense; the distinction that splits one question into two is the family's main rewording operation (*Sic et Non*'s rules: distinguish senses, check authenticity, prefer the later retraction). [M] (E)
5. **Dropping.** *Topics* I.11: not every problem is worth examining — those that need *perception* (is snow white?) or *punishment* (should one honour the gods?) are not dialectical problems; nor are things "too near" (no one doubts) or "too far" (no one could settle). [H] (E)
6. **Ascent stops.** At first principles known per se (*nous*), since demonstration cannot regress forever (*Post. An.* I.3); in the *quaestio*, at the authority the *sed contra* invokes. Who chooses: the discipline's principles, not the inquirer. [H] (E)
7. **Well-posedness.** A dialectical problem is one "on which people hold no opinion, or the many differ from the wise, or the wise among themselves" and which is *one* question (not several). [H] (E)
8. **Failure catalogue.** Fallacy of many questions (*Sophistical Refutations*); *petitio principii*; *ignoratio elenchi*; asking what needs perception; leaving an ambiguous term undivided; answering the article without a determination. [H] (E)
9. **Ladder.** The described process is a *later* form — the *quaestio* kept a fixed top (the text/authority) and the four-question order; the described process's floating top and self-reorganising structure are past what the family used. [M] (P)

### 6. Collingwood's logic of question and answer (with Gadamer's hermeneutics of the question)

**Mapping.** Every statement is an answer to a question; questions *arise* in an ordered complex out of presuppositions; the ascent from question to presupposition ends at *absolute presuppositions*, which are not answers to anything. [H] (E) — Collingwood, *An Autobiography* 1939 ch. 5; *An Essay on Metaphysics* 1940; Gadamer, *Truth and Method* II.3.

1. **Arising.** A question arises only when its presupposition is *made*; presuppositions are relative (themselves answers to prior questions) or absolute. A question's place is derived from presupposition, and the "logical efficacy" of a presupposition (its power to make a question arise) does not depend on its truth. [H] (E)
2. **Skipped question.** A question that "does not arise" is the family's name for one asked without its presupposition; the repair is to find the presupposition and ask *its* question first. Collingwood's method for a text: reconstruct the question the author was answering; if your question does not fit the text, you have skipped the author's. [H] (E)
3. **Descend or hold.** No explicit rule; the order of questions "is not indifferent" but is discovered historically, not chosen. Gadamer: the *priority of the question* — one cannot go down until one has "the question that is really being asked"; going up (to the question behind the text) is the primary move. Asymmetric: up is understanding, down is answering. [M] (E)
4. **Identity.** Same question iff it arises from the same presupposition in the same question-and-answer complex; a rewording that changes the presupposition is a different question (Collingwood's attack on "realist" readers who took Plato and Hobbes to be answering the same question about "the State"). [H] (E)
5. **Dropping.** A question that does not arise is simply not held. Postponement has no place; the family is retrospective (reconstruction), not prospective. [M] (P)
6. **Ascent stops.** At absolute presuppositions — those a practice makes without their being answers to any question and without their being true or false; they are found by *metaphysical analysis*, not chosen. This is the family's whole contribution to the stopping problem. [H] (E)
7. **Well-posedness.** Collingwood: a question is *right* only if it arises. Gadamer: a real question is *open* yet has *direction*; a "crooked" (schief) question is one posed so that no answer can reach the matter — it must be reformulated before it can be worked. [M] (E)
8. **Failure catalogue.** Asking a question that does not arise; treating an absolute presupposition as a proposition to verify (the "metaphysical" error); reading a text as answering your question rather than its own; crooked questions. Detection: the answer does not fit, or contradictions appear that dissolve when the question is reconstructed. [H] (E)
9. **Ladder.** The described process is *prospective*; this family is a mature theory of retrospective reconstruction and offers rules only for "what does this presuppose" and "where does ascent end". [H] (P)

### 7. Pólya's heuristic (with Nickles' constraint-inclusion model and Hadamard's well-posedness)

**Mapping.** A problem is an *unknown*, *data*, and a *condition*; the inquiry decomposes it into *auxiliary problems* posed "not for their own sake but because we hope their consideration may help us solve another problem", through variation (specialise, generalise, drop a condition, work backwards). [H] (E) — Pólya, *How to Solve It* 1945; [Nickles 1981, "What is a problem that we may solve it?" Synthese 47].

1. **Arising.** An auxiliary problem arises from a *strategy* for the original (a related solved problem, a special case, a generalisation); Pólya's *inventor's paradox* says the more ambitious problem may be easier — an explicit rule that ascent can be strategic. Nickles: a problem is a *demand* plus *constraints* on the solution; subproblems arise from the constraints, and the difference between what is known and what the constraints require is what remains to be worked. [H] (E)
2. **Skipped question.** "Is the condition sufficient to determine the unknown? insufficient? redundant? contradictory?" — asked in the *understanding* phase. An insufficient condition means a question above was skipped (what fixes the missing degree of freedom); the repair is to state the missing condition, or to solve "a part of the problem" conditionally (keep part of the condition, drop the rest, see how far the unknown is then determined). [H] (E)
3. **Descend or hold.** "If you cannot solve the proposed problem, try first some related problem" — descend when stuck, not before. Pólya's *looking back* is where commitments made below are checked against the whole. No symmetry claim; ascent (generalise) is one variation among several. [H] (E)
4. **Identity.** Nickles: same problem iff same demand and same constraints; adding a constraint *transforms* the problem (it becomes better defined, and is now a different problem). Pólya treats "a problem with the same unknown" as related, not identical. [M] (E)
5. **Dropping.** Drop a condition to see what it was doing; a redundant condition is dropped outright; a contradictory condition shows the problem must be reposed. No postponement rule. [H] (E)
6. **Ascent stops.** The proposed problem is given; the inventor's paradox permits going above it, bounded only by "can you now solve it?". Nickles: at the demand as set by the discipline. [M] (P)
7. **Well-posedness.** Pólya's four checks on the condition (above). Hadamard: existence, uniqueness, continuous dependence on data — a problem failing these is ill-posed and must be *regularised* (extra constraints added, i.e., a prior stated) before it can be worked; Nickles generalises this as "a problem is well-structured to the extent its constraints determine the solution". [H] (E)
8. **Failure catalogue.** Working without understanding (unknown/data/condition not stated); a plan that cannot be checked; a solution that does not use all the data or the whole condition (Pólya: "Did you use the whole condition?"); an ill-posed problem worked as if posed. Detected in *looking back*. [H] (E)
9. **Ladder.** The described process is the mature form for well-structured problems; Nickles wrote precisely to extend it to problems whose constraints are revised in the course of inquiry, and concedes that for those the structure is not a fixed tree. [M] (E)

### 8. Lakatos: proofs and refutations, and the methodology of research programmes

**Mapping.** Inquiry is a conjecture with a proof (a decomposition into lemmas) under attack by counterexamples; each counterexample poses the question "which lemma is guilty?", and the conjecture and its concepts are re-formed by *lemma-incorporation*; at the programme level, a *hard core* is held immune by decision while a *protective belt* absorbs refutations under a *positive heuristic*. [H] (E) — *Proofs and Refutations* 1976; *The Methodology of Scientific Research Programmes* 1978.

1. **Arising.** A *global* counterexample (to the conjecture) raises the question of the hidden lemma; a *local* counterexample (to a lemma) raises whether it is also global. P&R's numbered rules: set out to prove and refute; on a global counterexample, find and add a lemma the counterexample refutes and restate the conjecture with it as a condition; on a local-not-global counterexample, replace the refuted lemma; on any counterexample, seek by "deductive guessing" a deeper theorem. Questions arise from the *difference between the proof's assumptions and the case*. [H] (E)
2. **Skipped question.** A hidden lemma *is* a skipped question: the proof assumed something never stated. The rule is to insert it above (as a condition on the theorem) — never to abandon the conjecture outright and never to bar the monster. Monster-barring and exception-barring are the family's names for refusing to insert. [H] (E)
3. **Descend or hold.** MSRP's *negative heuristic*: do not direct modus tollens at the hard core; the *positive heuristic* is an ordered plan of which belt-questions to work next (Newton's sequence of planetary models). Commitments in the belt are expected to be undone; commitments in the core are protected by decision. Ascent to the core is forbidden while the programme is progressive. [H] (E)
4. **Identity.** Contested by construction: *concept-stretching* means "Is V−E+F=2 for all polyhedra?" is the same question only until "polyhedron" is re-defined; the family holds that the theorem's content *changes* through the dialogue and refuses a wording-based identity. The old conjecture is replaced by the improved one; it is not kept. [H] (E)
5. **Dropping.** A counterexample can be dropped only by proving it a monster under a proof-generated definition, and Lakatos treats this as the least rational move. At the programme level, a question is dropped when the programme that raised it degenerates. [H] (E)
6. **Ascent stops.** At the hard core — chosen by the programme's protagonists as a *methodological decision*, not by a criterion. Lakatos denies "instant rationality": one cannot tell at a moment that the core should be reopened. [H] (E)
7. **Well-posedness.** A conjecture is workable when it has a proof to analyse; a counterexample is workable when it is located (local or global). [M] (E)
8. **Failure catalogue.** Monster-barring; exception-barring; monster-adjustment; *ad hoc* belt modifications (no novel content); *degenerating problemshift* — from inside, the questions being worked are all repairs, none predicts anything new; detected only in retrospect by the content of the series. [H] (E)
9. **Ladder.** For mathematics the described process is the mature form; at the programme level, the family's known unworkable part is timing — it gives no rule for *when* to abandon the core (Feyerabend's critique). [H] (E)

### 9. Pragmatist inquiry (Peirce; Dewey)

**Mapping.** Inquiry begins in *genuine doubt* raised by a surprising fact, proceeds by abduction to hypotheses, chooses which to test by an *economy of research*, and ends when belief settles; Dewey: an indeterminate situation is *instituted* as a problem, and "a problem well put is half-solved". [H] (E) — Peirce, "Fixation of Belief" 1877; ["Note on the Theory of the Economy of Research" 1879](https://afinetheorem.wordpress.com/2012/01/16/note-on-the-theory-of-the-economy-of-research-c-s-peirce-1879/); Dewey, *Logic: The Theory of Inquiry* 1938.

1. **Arising.** Abduction: the surprising fact C; if A were true, C would be a matter of course; so A is worth suspecting. Questions arise from *anomaly*, and hypotheses (candidate answers) are what generate the next questions (what would follow if A?). Dewey: the problem is *derived from* the indeterminate situation; questions that are not so derived are "mere puzzles". [H] (E)
2. **Skipped question.** Dewey's phases (felt difficulty → location and definition → suggestion → reasoning → testing) put *definition of the problem* first; a hypothesis tested before the problem is instituted is the family's skipped question; the repair is to go back to the situation. [M] (E)
3. **Descend or hold.** Peirce's economy: test first the hypothesis with the best ratio of expected value to cost — cheapness, intrinsic likelihood, and *relation to other projects* (caution, breadth, incomplexity). This is the family's rule for which lower question to take up. Fallibilism: any settled belief may be reopened, so commitments below are always provisional. [H] (E)
4. **Identity.** Pragmatic maxim: two questions are the same if the practical consequences of their answers are the same; a "distinction without a difference" is a rewording, not a new question. [H] (E)
5. **Dropping.** A question is not worth holding if the doubt is *paper doubt* ("do not doubt in philosophy what you do not doubt in your heart"); it is dropped when belief settles. No postponement mechanism beyond economy (a low-value question waits). [H] (E)
6. **Ascent stops.** Nowhere in principle ("do not block the way of inquiry"); in practice where doubt is not felt. The inquirer's felt doubt chooses. [H] (E)
7. **Well-posedness.** Dewey: a problem is well put when it arises from the situation and states what would resolve the indeterminacy; Peirce: a hypothesis is admissible only if it is *testable* (experiential consequences). [H] (E)
8. **Failure catalogue.** Paper doubt; blocking inquiry (dogmatism); "the philosophic fallacy" (treating the outcome of inquiry as antecedent fact); testing before defining. Detected by asking whether anything would change if the answer differed. [M] (E)
9. **Ladder.** Mature; the described process's "worth holding" clause and "postpone with a default" are this family's economy and its fallibilism respectively; its tree structure is not. [M] (P)

### 10. Wicked problems, IBIS and dialogue mapping (Rittel & Webber; Kunz & Rittel; Conklin; QOC)

**Mapping.** Planning/design is argumentation: *issues* (questions) with *positions* and *arguments*, linked by relations (generalises/specialises, replaces, is-suggested-by, questions); the map is reorganised as the group talks. [H] (E) — [Rittel & Webber 1973](https://www.sympoetic.net/Managing_Complexity/complexity_files/1973%20Rittel%20and%20Webber%20Wicked%20Problems.pdf); Kunz & Rittel 1970 "Issues as elements of information systems"; Conklin, *Dialogue Mapping* 2006; MacLean et al., QOC 1991.

1. **Arising.** By IBIS relations: an issue is *suggested by* a position or argument; a position *raises* a consequent issue (QOC: options raise consequent questions). Rittel's property 9: "the existence of a discrepancy can be explained in numerous ways; the choice of explanation determines the nature of the resolution" — a question's place comes from the explanation chosen, not from presupposition. [H] (E)
2. **Skipped question.** Conklin's mapping practice: when the group argues positions with no question above them, the mapper writes the question they are answering and attaches them — insert above, in front of the group. Rittel's "no definitive formulation" means the skip is normal, not an error. [M] (E)
3. **Descend or hold.** Rittel: wicked problems have *no stopping rule* and "every solution is a one-shot operation" — commitments below cannot be undone, so the family's rule is to hold the top open and keep the argument going, deciding only when external limits (time, money) force it. Conklin: the "left-most" (root) question should be the *deontic* one (what should we do?), and the map may be entered at any node; up and down are alike in the notation (generalises/specialises are inverse links). [M] (E)
4. **Identity.** Conklin: a question that rewords one on the map is not added — the mapper points to the existing node; IBIS has an explicit *replaces* link for a reformulated issue, keeping the old one attached. [M] (E)
5. **Dropping.** No issue is deleted; positions are argued against; an issue made irrelevant stays with its status. QOC: a question with only one option is not worth holding (no design space). [M] (E)
6. **Ascent stops.** Rittel's property 8: "every wicked problem can be considered to be a symptom of another problem"; going up makes the problem broader and harder; "one should not try to cure symptoms", but the level at which to settle "depends on the self-confidence of the analyst and cannot be decided on logical grounds". Who chooses: the analyst, by confidence, not by criterion. [H] (E)
7. **Well-posedness.** IBIS: an issue is phrased as a question with at least two positions; Conklin lists question types (deontic, instrumental, criterial, meaning, factual, background, stakeholder) and requires each to be *one* type. Rittel denies well-posedness is reachable: "the formulation of a wicked problem is the problem". [H] (E)
8. **Failure catalogue.** *Issue explosion* (map grows faster than the group can hold); *type III error* (solving the wrong problem); "taming" a wicked problem (treating it as tame); mixing question types in one node; premature closure. Detected by the mapper, not by the notation. [M] (E)
9. **Ladder.** IBIS/gIBIS is mature but its known failure is capture cost (Shipman & McCall, Buckingham Shum); the described process is *inside* what the family found workable only because one party does most of the mapping. [M] (E)

### 11. Design framing and problem–solution co-evolution (Schön; Darke; Dorst & Cross; Alexander)

**Mapping.** Design is a *reflective conversation* with the situation: the designer *names* and *frames* the problem, makes moves, listens to the situation's *back-talk*, and reframes; problem and solution spaces co-evolve through *bridges*. [H] (E) — Schön, *The Reflective Practitioner* 1983; [Darke 1979, Design Studies 1(1)]; [Dorst & Cross 2001](https://www.repository.cam.ac.uk/bitstreams/62b76611-0dd0-414e-9a87-6fc755a26674/download); Alexander, *Notes on the Synthesis of Form* 1964.

1. **Arising.** Questions arise from *moves*: a partial solution posed in the solution space throws back new questions in the problem space (Dorst & Cross's co-evolution). Darke's *primary generator*: the designer fixes early on a simple organising idea, and the problem's questions are derived from it. So a question's place comes from a *commitment already made below*, inverting the tasking's presupposition order. [H] (E)
2. **Skipped question.** Schön: the situation "talks back" — a move produces consequences the frame did not foresee; that is the detector; the response is a *frame experiment* (try a new frame), not insertion of a question above the old. [H] (E)
3. **Descend or hold.** The family's rule is to descend *early and deliberately* (primary generator; "solution-focused" designers, Cross), because the higher question cannot be settled without a solution to test it against. Commitments below are expected to be undone by reframing; Schön's criterion for a frame: does it keep the inquiry moving, is the back-talk coherent, can it be solved? Up (reframe) and down (move) are alike in being *experiments*. [H] (E)
4. **Identity.** Not by wording: a frame is the same when the same things count as problems and solutions; Schön & Rein (*Frame Reflection* 1994) treat frame *conflict* as the case where two parties' questions look alike and are not. [M] (E)
5. **Dropping.** A frame is dropped when it stops producing coherent back-talk; questions inside it go with it. The primary generator itself is rarely dropped (Darke's finding, and the family's known pathology). [M] (E)
6. **Ascent stops.** Dorst's frame creation (2015): ascend from the problem to the *paradox* and *themes* (why does this matter to the people involved?) and stop where a new frame becomes fruitful — judged by its fruits, chosen by the designer. [M] (E)
7. **Well-posedness.** A problem is workable once framed — i.e., once a frame gives it a solution space; an unframed problem is not ill-posed but *unset*. [H] (E)
8. **Failure catalogue.** Design fixation (Jansson & Smith 1991: the primary generator holds past its use); solving the wrong problem; frame conflict mistaken for disagreement within a frame; "back-talk" ignored. Detected by incoherence of the situation's response. [H] (E)
9. **Ladder.** Alexander's 1964 method — decompose requirements into a *tree* of misfit sets and solve leaves upward — is this family's earlier form; Alexander repudiated it ("A City is not a Tree" 1965; 1971 preface). The described process, as a tree that reorganises, is the form the family *left*; co-evolution is its mature form. [H] (E)

### 12. Goal–subgoal problem solving in AI (GPS means–ends; AND/OR graphs; Soar's impasses; HTN planning)

**Mapping.** A goal is a difference between current and desired state; subgoals arise when the operator that would reduce the difference is not applicable; the structure is an AND/OR graph of subproblems, and in Soar every subgoal is created automatically by an *impasse* in decision-making. [H] (E) — Newell & Simon, *Human Problem Solving* 1972; [Laird, Newell & Rosenbloom 1987](http://www.jimdavies.org/summaries/laird1987.html); [Laird 2022 intro to Soar](https://arxiv.org/pdf/2205.03854).

1. **Arising.** GPS: from the *difference* between known and wanted (table of connections difference → operator); subgoal = make the operator applicable. Soar: from an impasse — *state no-change* (no operator proposed), *operator tie*, *operator conflict*, *operator no-change* (selected but cannot apply). HTN: from a *method* that decomposes a task into an ordered network of subtasks. [H] (E)
2. **Skipped question.** Soar's *universal subgoaling*: any decision the architecture cannot make becomes a subgoal — the skipped question is detected by the impasse and inserted *below* the current goal as a subgoal whose result resolves the impasse. Nothing is abandoned; the lower work is suspended. [H] (E)
3. **Descend or hold.** Descend on impasse only. When any change in a higher context resolves its impasse, *all subgoals below are removed automatically* — the family's clean statement that commitments below are undone by a higher answer (Soar's goal-dependency set enforces consistency of a subgoal's results with the higher state that produced it). Going up is never a move; only results return. [H] (E)
4. **Identity.** AND/OR *graphs* (not trees) merge identical subproblems syntactically; Soar's *chunking* learns the result of a subgoal as a rule so the same impasse does not recur — identity is "same conditions". [H] (E)
5. **Dropping.** Subgoals die with the impasse that created them; a goal is dropped when its difference is zero. No postponement with a default in this family (see family 13). [H] (E)
6. **Ascent stops.** The root task is given by the user or the top problem space; Soar's *problem-space hypothesis* says every goal is worked in a space, but the top space is external. [H] (E)
7. **Well-posedness.** A goal is workable when it is a state description or a difference the operators can address; in HTN, when a method exists for the task. [H] (E)
8. **Failure catalogue.** Goal loops (GPS had a repeated-goal check); infinite subgoal regress; thrashing between tied operators; chunks that over-generalise. Detected by the architecture (repeated impasse in the same state). [H] (E)
9. **Ladder.** GPS is the beginner's form; Soar the mature architecture, still developed. The described process is inside this family's workable range only for closed problem spaces. [H] (E)

### 13. Least-commitment planning and reason maintenance (NOAH; MOLGEN; Doyle's TMS; de Kleer's ATMS; default logic; CDCL solvers)

**Mapping.** Decisions are postponed until constraints force them; every belief carries its *justifications*; a *contradiction* triggers dependency-directed backtracking to the assumptions that produced it; *defaults* are assumptions held until something better arrives. [H] (E) — Sacerdoti, NOAH 1975; Stefik, MOLGEN 1981; Doyle, TMS AIJ 1979; de Kleer, ATMS 1986; Reiter 1980.

1. **Arising.** From *interactions* detected by critics (NOAH) and from *constraint propagation* (MOLGEN): a question arises when two partial decisions constrain each other. In a TMS, a question is a node with no valid justification. [H] (E)
2. **Skipped question.** A contradiction node whose support traces to an *assumption* (a belief justified by the absence of contrary belief) reveals a question that was never settled; the repair is to choose which assumption to retract (the *nogood* records the set so it is not re-entered). [H] (E)
3. **Descend or hold.** MOLGEN's layered control: *least commitment* — make only decisions that constraints force; when nothing is forced, *guess* (heuristic choice) with the ability to undo. Commitments below a retracted assumption are withdrawn by dependency, automatically. The ATMS holds several assumption-sets at once, so work proceeds under all unsettled higher answers simultaneously. Up and down are alike: both are assumption additions/retractions. [H] (E)
4. **Identity.** Nodes merge on identical propositions (syntactic); no semantic identity. [H] (E)
5. **Dropping and postponing.** This is the family's centre: to postpone is to *assume* a default, record the dependency, and continue; when the higher answer arrives, what rested on the default is retracted. Reiter: conflicting defaults yield multiple extensions; acting on one is *credulous*, on their intersection *sceptical*. A question made irrelevant is a node that has lost all consumers — it stays but nothing depends on it. [H] (E)
6. **Ascent stops.** At *premises* (nodes with no justification, given from outside) as distinct from *assumptions*; the distinction is the family's whole answer, and who marks a node a premise is the user. [H] (E)
7. **Well-posedness.** A question is workable when represented as a choice with recordable dependencies; a question whose consequences cannot be traced is unworkable for the mechanism. [M] (P)
8. **Failure catalogue.** Nogood explosion (ATMS); unfounded circular support; retraction cascades; guessing too early (MOLGEN's own diagnosis). Detected by the dependency network. [H] (E)
9. **Ladder.** Mature and current: CDCL SAT solvers (Chaff 2001 onward) are dependency-directed backtracking with clause learning, and dominate practice — the strongest recency evidence in this report that "postpone with a default, record why, retract by dependency" works at scale. [H] (E)

### 14. Decision analysis (Howard; Strategic Decisions Group practice)

**Mapping.** The top is a *decision*; every question held is either a decision node or an uncertainty node in an influence diagram; the *decision hierarchy* sorts what is taken as given, decided now, and deferred; *value of information* says which uncertainty to resolve first. [H] (E) — [Howard & Abbas, Foundations of Decision Analysis 2015](https://www.amazon.com/Foundations-Decision-Analysis-Ronald-Howard/dp/0132336243); [clarity test](https://en.wikipedia.org/wiki/Clarity_test); Spetzler, Winter & Meyer, *Decision Quality* 2016.

1. **Arising.** From *relevance*: an uncertainty is held only if it is relevant to a value or decision node (an arc in the diagram); a decision arises from the frame. The place is derived from *what changes the choice*, not from presupposition. [H] (E)
2. **Skipped question.** A decision treated as given, or a given treated as a decision — detected in *framing* by asking "can we actually change this?"; repaired by moving it between tiers of the hierarchy. [M] (E)
3. **Descend or hold.** *Value of information*: resolve an uncertainty before deciding only if the expected value of doing so exceeds its cost; otherwise decide under uncertainty. Deferred decisions are explicitly a tier ("decide later"), to be taken after the focus decisions. Commitments below a higher decision: the diagram's arcs show what a later answer would change; *sensitivity analysis* (tornado diagram) shows which uncertainties could flip the decision. [H] (E)
4. **Identity.** Two uncertainties are one if the clairvoyant's answer would be the same event; two decisions are one if their alternatives are the same set. [M] (P)
5. **Dropping.** An uncertainty whose range cannot change the decision (flat in the tornado) is dropped from the model; a question is postponed by fixing it at its base-case value and noting the sensitivity. [H] (E)
6. **Ascent stops.** At the *frame*, chosen by the decision maker with the analyst — the highest question is "what decision are we making?", and the family's guidance is to go up until the decision maker owns the decision and no further (a frame too wide is "boiling the ocean"). [M] (E)
7. **Well-posedness.** The *clarity (clairvoyance) test*: a question is fit when a clairvoyant who knew all future facts could answer it without exercising judgement; one that fails must be reformulated. This is the sharpest well-posedness criterion in the report. [H] (E)
8. **Failure catalogue.** Solving the wrong problem (type III error); analysis paralysis (VOI below cost); failing the clarity test; misplacing a decision in the hierarchy; unrecognised dependence between uncertainties. Detected in the decision-quality review (frame, alternatives, information, values, reasoning, commitment). [H] (E)
9. **Ladder.** Mature and in practice; the described process's "postpone with a stated default" is the hierarchy's deferred tier; its tree of questions is not a form the family uses (the diagram is a DAG). [H] (E)

### 15. Adjudication (US federal court doctrine; common-law pleading)

**Mapping.** A case holds a set of *issues* framed by the parties and decided by the court in a doctrinally ordered sequence (jurisdiction → justiciability → merits → remedy), with named rules for skipping, ordering, assuming, mooting, and precluding questions. [H] (E) — [Steel Co. 523 U.S. 83 (1998)](https://supreme.justia.com/cases/federal/us/523/83/); [Sinochem 549 U.S. 422 (2007)](https://supreme.justia.com/cases/federal/us/549/422/); [Pearson v. Callahan 555 U.S. 223 (2009)](https://caselaw.findlaw.com/court/us-supreme-court/555/223.html); Ashwander v. TVA 297 U.S. 288 (1936) (Brandeis, J., concurring).

1. **Arising.** From the *elements* of a claim and defence (each is a sub-issue whose answers jointly decide the claim) and from *threshold* doctrines that attach to every case whether or not raised. A question's place is derived from doctrine, not from strategy. [H] (E)
2. **Skipped question.** *Sua sponte*: a court must raise subject-matter jurisdiction itself even if no party did — the one question always inserted above. Steel Co. forbids "hypothetical jurisdiction" (deciding merits while assuming jurisdiction). Otherwise the *party-presentation principle* (United States v. Sineneng-Smith 2020) forbids the court inserting questions the parties did not raise. [H] (E)
3. **Descend or hold.** Steel Co.: jurisdiction before merits, mandatory. Ruhrgas/Sinochem: among threshold grounds, any order. *Ashwander*: do not decide a constitutional question if the case can be disposed on a narrower ground — descend to the lower question first. *Pearson v. Callahan* made the Saucier two-step (decide the constitutional question first, then whether the law was clearly established) *discretionary* — the family reversed a mandatory ordering rule after finding it wasteful. "Assuming without deciding" lets the court proceed conditionally; what it says under the assumption is *dicta*, and dicta do not bind — commitments made below an unsettled higher question are explicitly non-binding. [H] (E)
4. **Identity.** *Issue preclusion*: the same issue if "actually litigated and necessarily decided" (Restatement (Second) of Judgments §27); Supreme Court Rule 14.1(a): only questions "set out in the petition, or fairly included therein" are considered — a reworded question counts if fairly included, and parties may not reframe it later. [H] (E)
5. **Dropping and postponing.** *Mootness*: a question the events have made irrelevant is dismissed (exceptions: capable of repetition yet evading review, voluntary cessation). *Ripeness*: not yet fit; dismissed without prejudice. *Waiver/forfeiture*: a question not raised below is lost on appeal (save plain error). *Advisory opinions* are forbidden — a question with no live controversy is not held at all. Postponement with a default: interlocutory relief (preliminary injunction on likelihood of success) preserves the status quo while the merits stand open. [H] (E)
6. **Ascent stops.** The parties choose the top (the complaint's claims; the questions presented); the court chooses how little to decide (*judicial minimalism*, Sunstein 1999: decide the case on the narrowest ground). *Stare decisis*: a settled question is not reopened without special justification. [H] (E)
7. **Well-posedness.** *Standing* (injury, causation, redressability); a *case or controversy*; pleading plausibility (Twombly/Iqbal); a question of law vs of fact determines who answers it. [H] (E)
8. **Failure catalogue.** Advisory opinion; hypothetical jurisdiction; reaching out to decide; dicta mistaken for holding; deciding a forfeited issue; answering a question not presented. Detected on appeal or by the court's own justiciability screen. [H] (E)
9. **Ladder.** Common-law pleading forced *joinder of issue* on a single question — a form the family abandoned (Field Code 1848, FRCP 1938) as unworkable. The described process is the mature form here, save that the family has no analogue for one party doing most of the inquiry: the court decides but does not frame. [H] (E)

### 16. Inquiry teaching (Collins & Stevens' cognitive theory of inquiry teaching)

**Mapping.** A teacher who knows the target theory holds an *agenda* of goals and subgoals derived from the diagnosed gaps in the student's model, and chooses each question by strategy rules (counterexample, vary a case, entrap, trace consequences to a contradiction). The mapping is inverted relative to the shape: the second party does the inquiry and the first steers. [M] (E) — [Cognitive Theory of Inquiry Teaching](https://en.wikipedia.org/wiki/Cognitive_Theory_of_Inquiry_Teaching); [Collins & Stevens, ERIC ED282825](https://files.eric.ed.gov/fulltext/ED282825.pdf).

1. **Arising.** From the *difference* between the student's model and the target theory; each diagnosed error or omission becomes an agenda item. [M] (E)
2. **Skipped question.** The teacher's strategies deliberately *use* skipped presuppositions (entrapment: ask a question with a false presupposition to see if the student catches it). A student's skipped question is added to the agenda above its dependents. [M] (E)
3. **Descend or hold.** Priority rules on the agenda (my recollection of them: errors before omissions; earlier steps of the theory before later; shorter fixes before longer; more important factors before less). [L] (E)
4. **Identity.** By diagnosed model error, not by wording. [M] (P)
5. **Dropping.** An agenda item is dropped when the student's model no longer shows the error. [M] (E)
6. **Ascent stops.** At the target theory the teacher holds; chosen by the teacher. [H] (E)
7. **Well-posedness.** A question is fit when it discriminates between the student's model and the target (a case that would come out differently). [M] (P)
8. **Failure catalogue.** Questions that do not discriminate; the student fixating on a factor; the teacher telling rather than asking. [M] (E)
9. **Ladder.** Implemented in early ITS (WHY, 1977); mature as a description of expert tutors. [M] (E)

### 17. Root-cause analysis (Ohno's 5 Whys; Why–Because Analysis; Goldratt's current reality tree)

**Mapping.** Each "why" is an ascent to a higher question; the chain stops at a cause whose removal prevents recurrence and lies within the organisation's control. [H] (E) — Ohno, *Toyota Production System* 1988; Ladkin, WBA; Goldratt, *It's Not Luck* 1994.

1. **Arising.** Purely by ascent: each answer poses the next why. WBA adds the *counterfactual test* (would the effect have occurred without this cause?) and *causal sufficiency* to license each link. [H] (E)
2. **Skipped question.** A link that fails the counterfactual test reveals a missing intermediate cause; insert it. [M] (E)
3. **Descend or hold.** No descent; the family only ascends. [H] (E)
4. **Identity.** WBA merges nodes describing the same event; 5 Whys has no rule. [M] (E)
5. **Dropping.** A why-branch outside the system boundary is stopped (WBA's stop rule). Goldratt: the *core problem* is the root that accounts for most undesirable effects; other roots are dropped. [M] (E)
6. **Ascent stops.** Ohno: where fixing prevents recurrence and the fix is in your control (his example ends at a missing strainer, not at "the pump was overloaded"). WBA: at the system boundary. Goldratt: at the core problem. [H] (E)
7. **Well-posedness.** WBA's *Categories of Legitimate Reservation* (Goldratt) are a checklist: clarity, entity existence, causality existence, cause insufficiency, additional cause, cause–effect reversal, predicted-effect existence, tautology. [M] (E)
8. **Failure catalogue.** Stopping at a symptom; a single linear chain where causes are multiple; the investigator's knowledge bounding the chain; stopping at "human error" — the criticism in Card, "The problem with '5 whys'", BMJ Quality & Safety 2017. [H] (E)
9. **Ladder.** 5 Whys is the beginner's form and is documented as unreliable; WBA and fault trees are the mature form. [H] (E)

### 18. Talmudic dialectic (the *sugya*)

**Mapping.** A recorded inquiry on a fixed text holds *kushyot* (difficulties: contradiction between sources, or with reason), *terutzim* (resolutions, usually by distinguishing cases), and questions that *stand* (*teiku*), with explicit default rules for acting while a question stands. [M] (E) — secondary literature; I have not verified individual passages.

1. **Arising.** From contradiction between authorities or between a ruling and a case. [M] (E)
2. **Skipped question.** The resolution "here in case X, there in case Y" inserts the distinction that was never asked, above both sources. [M] (E)
3. **Descend or hold.** Not a rule of the form; questions are pursued as raised. [L] (P)
4. **Identity.** The Gemara marks a question as "the same as" one already asked and does not re-work it. [M] (E)
5. **Dropping and postponing.** *Pshita!* ("obvious!") rejects a question whose answer is already entailed — unless a *mahu d'teima* ("you might have thought…") shows a plausible alternative, which reinstates it; this is an explicit non-triviality test. *Teiku* leaves a question standing, and halakhic *safek* rules supply the default meanwhile (doubt on a biblical matter: stringent; on a rabbinic matter: lenient; in money, the possessor keeps). [M] (E)
6. **Ascent stops.** At the fixed text (Mishnah/Torah), whose truth is not questioned, only its meaning. [H] (E)
7. **Well-posedness.** Non-trivial (survives *pshita*) and grounded in a source. [M] (P)
8. **Failure catalogue.** Trivial question; forced resolution (*dochak*); resolution that contradicts a third source. [L] (E)
9. **Ladder.** Mature and still practised; not a self-reorganising structure — the record is fixed once redacted. [M] (E)

## What the tasking smuggled in

- **A tree with "above" and "below".** The description assumes questions sit in a hierarchy with a single ascent. Families 3 (partially ordered stack), 12 (AND/OR *graph*), 13 (dependency network), 14 (DAG), 11 (co-evolving spaces, and Alexander's repudiation of the tree) do not share it; family 10 uses generalises/specialises as symmetric links rather than a rooted tree.
- **Presupposition as the ordering principle.** Families 1, 2, 5, 6 order by presupposition; 3, 7, 12 order by *strategy for the parent*; 9, 14 by *value*; 11 by *commitment already made below*. The tasking's "what the newcomer presupposes" is one family's vocabulary offered as the neutral one.
- **One engaged question at a time.** Families 13 (ATMS: many contexts at once) and 11 (a move in the solution space is simultaneously work on several questions) deny it; 3 allows a partial order.
- **Settled/unsettled as binary.** Families 2 (bracketing), 13 (defaults with dependencies), 14 (probabilities, sensitivity), 15 (dicta vs holding; interlocutory relief) treat commitment as graded or conditional.
- **"Arrives".** The description treats newcomers as external events. In most families questions are *generated* by the method (evocation, impasse, back-talk, counterexample); only 3, 4, 10, 15 model a second party as the source, and there the other party is a full participant, not a consultee.
- **"Mostly one party, with a second consulted".** The dialogue families (3, 4) are symmetric; 2's second party is an oracle that answers but never decides; 15's deciding party (the court) is the *inquirer*, and the framing party (the plaintiff) is not consulted but binding; 16 inverts the roles. None matches the arrangement as described.
- **Ascent as "symptom of a higher one".** This is Rittel's phrasing (property 8) and carries Rittel's conclusion — that the stopping level is a matter of confidence, not logic. Families 5, 6, 8, 12, 13, 15 have *criteria* for the top (per-se principles, absolute presuppositions, hard core, root task, premises, party presentation), which the "symptom" framing presumes do not exist.
- **Identity as rewording.** Every family with an identity rule states it semantically (answer set, partition, consequences, model error, issue actually decided), never as a wording relation. The tasking's "rewording" assumes surface text is the unit.
- **Rules separable from storage and display.** Family 10's central failure (capture cost) and family 3's implementation history say the notation *is* the rule set: what can be represented determines what can be accommodated. The tasking's exclusion of storage removes the material where that family locates the difficulty.
- **"Reorganises itself".** In every family a *party* reorganises under rules; only 12 and 13 have the structure reorganise automatically, and both do so only because their problem spaces are closed.
- **"Worth holding" as a property of the question.** Families 9 and 14 make it a property of the *cost and value* of answering; family 15 makes it a property of the *controversy* (mootness, standing), not of the question.

## Nothing to take

**Refused (no one-or-two-sentence structural mapping):**
- TRIZ — contradiction matrices and inventive principles; nothing on how questions are held or reordered.
- Dung-style abstract argumentation — a structure of *arguments* under attack, with acceptability semantics; questions are not elements.
- Kanban, GTD, backlog grooming, Zettelkasten — tracking and storage, which the tasking excludes; their rules (WIP limits, next-action) are about flow, not question structure.
- Kuhn's normal science — the paradigm supplies the puzzles; it has an account of anomaly and crisis (bearing on 6 and 8) but no rules for the structure between; folded into the framing note on 8.
- Popper's P1 → TT → EE → P2 — a schema, not a rule set; its rules live in Lakatos (family 8).
- Bayesian optimal experimental design — the mapping is only "which uncertainty next" and is family 14's VOI in another notation.
- Cynefin, Theory of Constraints as a whole — TOC's trees and reservation categories were taken into family 17; the rest is sense-making typology.
- Consulting issue trees (Minto pyramid; MECE; hypothesis-driven "day-one answer") — the mapping is statable (top key question decomposed MECE into sub-questions, hypothesis first), but the rules are Pólya's decomposition plus a partition constraint and a "commit early" heuristic already present in families 7 and 11; nothing distinct to report beyond MECE as an identity/overlap test.
- Hermeneutic circle (Gadamer) — folded into family 6; the part with rules (priority of the question, crooked questions) is there; the rest is not rules.

**Looks portable and is not:**
- Erotetic implication (family 1) requires answer sets fixed in advance; for a question whose answers are designs, the narrowing clause cannot be evaluated, so the "serving" relation does not transfer, only its intent.
- Soar's impasse detection (family 12) needs a closed problem space with proposal knowledge; without one, "no operator proposed" is the permanent state and every step is an impasse.
- Hadamard well-posedness (family 7) is for equations; "continuous dependence on data" has no counterpart for a design question.
- Legal sequencing doctrines (family 15) depend on adversarial framing, finality, and appellate review; "assume without deciding" works because dicta are non-binding *by institution* — there is no institution in a one-party inquiry to make it so.
- 5 Whys (family 17) is documented as unreliable by the substrate that uses it most (healthcare safety, 2017); its stopping criterion is the only part with support.
- The QUD "Big Question" (family 3) is a formal top for discourse coherence, not a criterion for where a *given* inquiry should stop ascending.

**Did the pass return usable material?** Yes: (a) five distinct derivations of a question's place (presupposition; strategy for the parent; known-vs-wanted difference; value; commitment already made below), which do not reduce to one; (b) three explicit detectors for a skipped question (presupposition rule, impasse, accommodation from a plan) and two for "the subject has shifted" (dialectical shift; back-talk incoherence); (c) four distinct rules for postponing with a default (assumption with dependency; deferred tier; safek defaults; assuming arguendo with non-binding dicta); (d) two sharp well-posedness tests (clarity/clairvoyance; sound-and-informative) and one rejection test (pshita/mahu d'teima); (e) six distinct stopping criteria for ascent that the families do not reconcile; (f) three families (11 Alexander, 15 single-issue pleading, 17 5 Whys) that record a *tree* or *single chain* form as something they abandoned. The families disagree on whether the structure is a tree, on whether descent before the higher answer is a fault (2, 5, 15-Steel Co.) or the method (11, 13, 15-Ashwander), and on whether the top is chosen by criterion (5, 6, 8, 12, 13) or by confidence (10) — these disagreements are left standing.
