У прошедшей проверки этот список пуст, и запись стала короче прежней. Если скрипт упал и отчёта не напечатал, остаются последние строки трейсбека. **[01-0011.0120 — a rule's block leaves a file once its rules file stops naming it](docs/tickets/done/01-0011.0120-a-dropped-target-loses-its-block.md)** (`f6cd2dd`). `--install` теперь вместе с целями планирует удаление блоков своего же источника из файлов, которые rules-файл больше не называет. Удаление делается тем же разрезом, что и `--retract`: файл возвращается байт в байт к виду до установки. Отчёт показывает, что было удалено. Если любая цель отказала, не пишется ничего. Чужие блоки и блоки без rules-файла остаются на месте. Случай из `studies` теперь закрывается одной правкой rules-файла и одним `--install`, без восстановления старого файла.
