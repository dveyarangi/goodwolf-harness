**What `.0060` builds.** It works out when a mechanism is due for a re-check. The meta-rules or the surfaces a mechanism rests on have moved since its doc was last checked, so something now says "mechanism X is due." That verdict only helps if someone sees it.

So "X is due" shows up only if someone runs the command that computes it. `.0120`'s header points at a failure that already happened: `mechanisms.py --check` was a check nobody ran, and its silence was taken to mean everything was fine. `.0120` finds out what Claude Code, Codex and Cursor can each put in front of the agent without being asked, such as a hook's output at session start, and whether the harness uses that at all. The dependency amounts to this: don't build an alarm until you know where it can ring.

**Why I think it doesn't have to wait.**
1. **The logic and the channel are separate, and `.0060` already separates them.** It says where the verdict is seen is `.0120`'s question, and it puts "the wake surface itself" out of scope.
