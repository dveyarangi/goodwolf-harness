PART: The destructive guard of --replace-clone: what "a clean clone, HEAD equal to the repository's commit" can actually prove, and what the wipe plus fresh git init destroys (the .git directory with history, remote, other branches, unpushed commits, stashes, ignored or untracked files), including the fact that the clone being wiped is also the installer's own source.
CONTRACT CHANGE: The flag's promise changes from "turns a fresh, disposable clone into an install" to a destructive operation whose safety rests on a check that cannot tell a person's fresh clone from a harness developer's working clone. Examining it may move the boundary (the installer works from a copy outside the target, or refuses unless the clone matches a fetched origin state), or may show the flag cannot be made safe. That in turn changes the "restorable by re-clone" risk claim, which does not hold for unpushed or unpublished work, and changes the README and refusal text that would advertise the path.
REASONING: The draft commits to one shape: the installer converts the cloned harness into an install in place, behind an explicit flag, with a README line and a refusal line. The cost and risk paragraph names only one risk, a developer running it by mistake, and dismisses it as recoverable by re-cloning and as guarded by the explicit flag. Both dismissals are unexamined. A clean working tree with HEAD at "the repository's commit" says nothing about unpushed commits, other branches, stashes or ignored files, and the installer cannot know the repository's commit offline. A developer's clone with local-only history is wiped irrecoverably, so the blast radius is the data the flag destroys, not a local detail. The source-equals-target problem is also load-bearing: the installer is deleting the tree it installs from, so it must copy or fetch the core first, and that changes the mechanism. The same installer already has a refusal for "the source itself as target", so the new flag reverses an existing boundary, not an isolated one. Other candidates, such as test coverage, the flag's name, and the exact wording of the README line, can be settled later and locally. The alternative of teaching a different phrase, and the premise that the host clones first, were weighed in the draft and are not in question.
