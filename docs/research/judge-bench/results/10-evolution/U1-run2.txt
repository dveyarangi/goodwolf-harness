PART: The proposed rule that "a premise nobody expects to move is ground and is not written" is adopted without examining that it contradicts the draft's own argument (at write time nobody knows which change will come) and removes from the store exactly the links that would catch the rare, large shifts.
CONTRACT CHANGE: The link's coverage promise changes. As drafted, a change in an assumed answer finds only the answers whose premise was judged live when written. Once examined, either every premise taken is written (with the store holding the weight or solidity separately, which the person's closing remark about "закостенелость" points to), or ground is recorded by some other means. Either way, "when an assumed position changes, each question that assumed it is judged" holds for the dramatic changes (the team is gone, the service does not exist) and not only for the expected ones. That in turn changes what the single link must carry (a weight or liveness mark) and what the check can report.
