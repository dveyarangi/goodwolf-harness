PART: The draft makes the question store the durable "index of the product's answers" by having each generated question point at a place in untouched code or docs, but never examines what keeps those pointers true (and the question still current) once that code and those docs change, which is the same staleness problem the marks were meant to solve.
CONTRACT CHANGE: The store's promise changes from "an index of where the product's answers live" to either a snapshot as of the arrival pass, or an index backed by a staleness mechanism (pointer anchoring, re-check by /maintain, expiry, re-run of the pass). That in turn changes what a generated question is, how long "found, not decided" lasts, and whether the product document may derive from these entries at all.
REASONING: The draft commits to a shape: a second pass writes findings as questions hung under the cause they answer, each with a pointer into unmarked code or docs; the store then serves as the answer index, and the product document derives from it. It answers the person's doubt about marks ("if you see a way") with "no marks in code, pointers in questions". But a pointer into code nobody has organised or tagged has exactly the weakness the person named: the code moves, the pointer silently stops pointing, and nothing in the draft says who notices. The tree's own open question q-0033.0005 is precisely how a derived product view stays true. I checked the tree: q-0018.0011.0004 and q-0033.0005 record no mechanism for code-pointer drift, and q-0001.0023 covers answers changing, not the code location of an answer changing. This is load-bearing because the product document, the release note and the "index" all derive from these entries, so a false pointer makes several outputs wrong at once, and fixing it later changes the entry's form. Other candidates (the volume bound via the load-bearing test, the new closure kind, the root staying open, the cheap experiment) are real but are local, are put to the person as explicit choices, or can be settled later without changing what is committed.
