PART: The proposed rule that a premise nobody expects to move is "ground" and is not written leaves unexamined what finds an answer when such an unwritten premise does move, which is the case the question was raised for.
CONTRACT CHANGE: The mechanism's promise ("a change in the assumed answers finds the answer that assumed them") would hold only for premises the writer foresaw as live. Either every taken premise is recorded (perhaps with the pin to B's answer, as the earlier draft had it, so the script and not the writer's foresight finds the changed ones), or the contract must say outright that a shift in an unwritten premise finds nothing. The boundary between agent judgement at write time and the script's mechanical finding moves, and with it the rule to judge each assumer at a change, since the rule can only reach linked answers.
REASONING: The draft commits to a single assumes link whose consequence (answer in doubt or question in doubt) is decided at the change, with depends on shrunk later to ordering. The collapse into one link follows from the person's last objection and the existing record, and the retained blocking-versus-ordering split is explicitly deferred, so those pass as detail that can be settled later. The ground exemption does not pass. The draft's own argument is that nobody knows at write time which change will come, yet it asks the writer to decide at that moment which premises will never move. The record (q-0001.0023, q-0001.0022) says the question arose from the landscape moving rarely but moving purpose and structure together; a premise that has sunk into ground is exactly such a late, large shift. Densification is also what the person pointed at, so the exemption removes links precisely as they get costly to miss. The earlier draft's pin to the exact answer taken, which let the script find assumers without the agent's memory, is dropped silently and the new text does not say how assumers are found, which is the same gap. This changes what the shape promises, so it is not a local detail.
